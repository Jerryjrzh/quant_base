这是一张非常典型的“超级主升浪（Super Trend / 妖股）”的走势图。以中船特气（688146）为例，它呈现的是一段完全无视地心引力、沿着 5 日/10 日均线单边斜率向上的暴力拉升。

作为量化架构师，我必须首先指出一个核心矛盾：**你当前大获成功的 V4.7 系统（`entry_pos <= 0.5`，深蹲接针，固定 10% 止盈）是绝对抓不住、也拿不住这种票的。**

你现有的系统是“左侧均值回归（抄底）”，而这张图是极致的“右侧动能突破（追涨）”。如果用现在的系统，你在它刚启动 10% 的时候就会被强行止盈卖飞。

要在当前项目中把这类票纳入射程，我们需要在 `screenergf.py` 中开辟一条完全独立的“动能突破策略（Scheme T - Trend）”，并配以完全不同的出入场和回测逻辑。

以下是具体的拆解、指标构建与回测补齐方案：

### 一、 指标特征降维（解构中船特气的走势）

从你提供的截图中，我们可以将这种“主升浪”翻译为机器能懂的量化特征。

#### 1. 爆发前的“蓄势确认”特征（左侧/启动初段）

在图中大涨之前（大约在 4 月中旬），股票经历了漫长的横盘。

* **均线密集（MA Clustering）** ：MA5, 10, 20, 60 在爆发前紧紧靠拢。这在数学上叫“波动率收敛”。
* **MACD 零轴水上飞** ：MACD 在爆发前，DIF 和 DEA 拒绝下穿零轴，在零轴附近粘合后再次金叉发散。
* **RSI 温和修复** ：RSI(6) 从 50 左右的中性区突然翘头向上，突破 60。

#### 2. 爆发后的“主升跟踪”特征（右侧/持仓段）

进入 5 月、6 月后，指标呈现出了让散户害怕、但量化程序最喜欢的特征：

* **均线多头排列（Bullish Alignment）** ：**$MA_5 > MA_{10} > MA_{20} > MA_{60}$** 且发散向上。
* **指标高位钝化（Indicator Blunting）** ：
* 图中的 KDJ 极高（K=94, D=92, J=97）。
* 图中的 RSI 极高（RSI6=92）。
* *核心认知* ：在主升浪中，**超买不是卖出信号，超买钝化是极度强势的标志！** 只要 RSI 不跌破 70，趋势就没有结束。

### 二、 如何在当前项目中增加“主升浪（Scheme T）”？

为了不污染你目前胜率极高的“抄底系统（Scheme C）”，我们需要在代码中增加双轨制。

#### 1. 在 `screenergf.py` 中新增选股逻辑

你需要写一个新的函数 `apply_super_trend_strategy(df)`：

**Python**

```
def apply_super_trend_strategy(df, stock_code):
    """Scheme T: 动能突破与主升浪策略"""
    if len(df) < 60: return None
  
    current = df.iloc[-1]
  
    # 1. 均线多头排列判定
    ma5, ma10, ma20, ma60 = current['ma5'], current['ma10'], current['ma20'], current['ma60']
    if not (ma5 > ma10 and ma10 > ma20 and current['close'] > ma5):
        return None # 不满足最基本的强势特征，直接淘汰
      
    # 2. 爆发前/爆发初期的确认 (MACD 水上金叉/拒绝死叉)
    macd, dif, dea = current['macd'], current['dif'], current['dea']
    if dif < 0 or dea < 0: 
        return None # DIF/DEA 必须在零轴之上 (水上强势区)
      
    # 3. 寻找均线密集后的突破 (爆发前确认)
    # 计算近 20 天最高价和最低价的振幅，寻找波动率收敛后的放量突破
    recent_20_high = df['high'].tail(20).max()
    recent_20_low = df['low'].tail(20).min()
    squeeze_ratio = (recent_20_high - recent_20_low) / recent_20_low
  
    # 4. 指标判定：RSI 必须处于进攻区 (>65)，允许钝化
    rsi6 = current['rsi6']
    if rsi6 < 65:
        return None
      
    return {
        'signal': True,
        'strategy_type': 'Scheme_T', # 标记为趋势策略
        'score': 95, # 基础分
        'squeeze_ratio': squeeze_ratio,
        'rsi6': rsi6
    }
```

#### 2. 修改 `backtester.py` 中的价格评估与出入场

对于 Scheme T（主升浪），**绝对不能用原来的“折价挂单”和“固定 10% 止盈”！**

* **入场（追击）** ：因为是突破，股票很难回调。
* **挂单价** ：`trigger_buy = current_price * 1.0`（甚至允许市价单 `+0.5%` 抢筹）。不要等深蹲，主升浪没有深蹲。
* **止损（防假突破）** ：
* **防守位** ：大阳线启动的底部，或者动态的 MA10。一旦收盘跌破 MA10，无条件止损。
* **止盈（让利润狂奔）** ：
* **彻底关闭固定止盈（TP）** 。不要设 10% 或 20% 的天花板。
* **采用均线跟踪止盈（Trailing by MA）** ：只要收盘价不跌破 MA10（或 MA20），就死死拿住。图中中船特气从 40 涨到 298，全程收盘价几乎没有跌破过 20 日线。

### 三、 如何补齐回测相关数据？

既然开辟了新策略，我们必须通过回测来验证。针对“主升浪”的回测，你需要对原有的流程做如下补齐：

#### 1. 重新定义 Y 标签（寻找历史大牛股）

你需要写一个脚本，遍历历史所有股票，找出那些在 30 个交易日内，区间最大涨幅（MFE）超过 50% 的波段。这些波段的起点，就是我们机器学习模型（GBM）需要学习的“正样本”。

#### 2. 补齐 GBM 的特征入参 (Feature Engineering)

目前的 GBM 是为抄底设计的（特征是偏离度、超跌等）。为了让 GBM 能预测“谁会走主升浪”，你需要在 `pricing_gbm.py` 或特征构造模块中补齐以下特征传入模型：

* **均线紧凑度 (MA_Density)** ：**$MA\_Density = \frac{Max(MA_5, MA_{10}, MA_{20}, MA_{60}) - Min(MA_5, MA_{10}, MA_{20}, MA_{60})}{Min(MA_5, MA_{10}, MA_{20}, MA_{60})}$**。值越小，说明均线越密集，越是起爆前的征兆。
* **相对强度强度 (RSI_Slope)** ：RSI 近 3 天的斜率。起爆点通常伴随 RSI 的陡峭拉升。
* **量能配合度 (Vol_Ratio_MA20)** ：当日成交量与 20 日均量的比值。突破必须伴随放量（如图中右侧的红柱）。

#### 3. 运行隔离回测 (A/B Test)

在 `walk_forward_tester_s.py` 中，当判定 `strategy_type == 'Scheme_T'` 时：

1. 跳过原有的 `entry_pos <= 0.5` 过滤限制（突破必然是高位 `entry_pos > 0.8`）。
2. 记录 `MA10` 跌破事件作为出场条件，统计这段时间能吃到的 MFE。
3. 单独输出一份 `trend_calendar_trades.csv`。

### 总结行动建议

主升浪策略（Scheme T）和抄底策略（Scheme C）就像矛与盾，它们适用的市场环境完全互斥。

 **现在的当务之急是：**在你的系统中并行增加这个逻辑分支，并且**不要用现在的 GBM 模型去预测突破股** （因为现在的模型是用抄底数据训练出来的，会把突破股打低分）。你需要为这类票单独训练一个小型的 `trend_gbm.pkl`。
