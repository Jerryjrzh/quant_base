# Super Trend Grok Review 实验报告

> 时间：2026-06-11  
> 对照实验：原版 scanner (EDA P95 阈值) vs Grok review 修改版 (翻倍阈值)  
> 训练器：`super_trend_ml_trainer.py` (lr=0.01, AUC 早停, 1000 round)

---

## 一、实验背景

Attempt 4 训练结果（原版 scanner + EDA P95 阈值）：AUC 0.6912，@0.65 Precision = 32.5%，距 60% 目标差距大。Grok review 认为根因是**正样本标签过于宽松**（43-54% 涨幅只是"普通反弹"），建议大幅收紧至翻倍标准。

我方评估认为 Grok 的 P0 建议（MIN_GAIN 翻倍）过于激进，会导致正样本锐减，但仍决定实验验证。

### 2.2 T0 回溯收紧（P2）

| 条件 | 原版 | Grok 版 |
|------|------|---------|
| 涨幅门槛 | > 3% | **> 5%** |
| 量比门槛 | > 1.5 | **> 2.0** |

### 2.3 负样本增强（P3）

新增 3 个子类型：
- **fake_breakout**：日涨幅 ≥ 5% 但 22d MFE < 10%（高涨幅假突破）
- **volume_trap**：量比 ≥ 2.0 且 MAE < -10%（放量陷阱）
- **weak_momentum**：普通弱势（涨幅/量比均不突出）

### 2.4 增强特征工程（P1：+8 个新特征）

| 特征 | 说明 | 生效状态 |
|------|------|---------|
| ma_bull_alignment_days | MA5>MA10>MA20>MA60 连续天数 | **缺失** — MA5/10/20 未计算 |
| bias_ma20 | 价格偏离 MA20 百分比 | **缺失** — MA20 未计算 |
| bias_ma60 | 价格偏离 MA60 百分比 | **生效** ✅ |
| atr_percentile | ATR 在 60 天中的百分位 | **缺失** — ATR 未计算 |
| boll_width | 布林带宽度 | **缺失** — BOLL 未计算 |
| pre_breakout_vol_shrink_days | 突破前连续缩量天数 | **生效** ✅ |
| vol_breakout_ratio | T0 量 / 前 5 日均量 | **生效** ✅ |
| price_position_120d | 价格在 120 天中的位置 | **生效** ✅ |

4/8 特征因 `calculate_all_indicators()` 未计算 MA5/MA10/MA20/ATR/BOLL 而缺失。

## 五、结论与评估

### 5.1 Grok review 建议的效果

| 维度 | 评价 |
|------|------|
| AUC 提升 | ✅ CV AUC +6%，方差减半，模型更稳定 |
| Precision 提升 | ⚠️ @0.65 仅 +1.2%，@0.70 +6.4%，有改善但远未达到 60% 目标 |
| 正样本纯度 | ✅ MFE 中位数 113%，确实是"超级主升浪" |
| 样本量代价 | ❌ 正样本锐减 82%（45K → 8K），触发数大幅下降 |
| 特征信号 | ⚠️ 正/负概率分离度无变化（0.078 → 0.079） |

### 5.2 核心判断

**Grok review 的诊断部分正确（特征信号弱），但修复路径不是最优。**

收紧阈值确实提升了 AUC（正样本更纯粹，模式更清晰），但 Precision 提升有限。瓶颈不在标签质量，而在**特征分离度**。模型输出概率的分离度（正 0.148 vs 负 0.069 = 差 0.079）与原版几乎相同，说明即使标签再纯，如果特征无法区分，Precision 也上不去。

### 5.3 新特征的价值验证

`bias_ma60` 登顶特征重要性，`vol_breakout_ratio` 和 `price_position_120d` 进入 Top 10，**证明增强特征工程方向正确**。但 4/8 个新特征因指标缺失未能提取：

| 缺失特征 | 预期价值 | 理由 |
|----------|---------|------|
| ma_bull_alignment_days | **极高** | 多头排列是主升浪最经典的信号 |
| bias_ma20 | 中 | 短期乖离率，补充 bias_ma60 |
| atr_percentile | 中 | 波动率收缩后突破是常见模式 |
| boll_width | **高** | 布林带收口（squeeze）是爆发前兆 |

## 六、下一步建议

### 优先级 P0：补齐缺失指标

在 `calculate_all_indicators()` 中新增：
- MA5 / MA10 / MA20（简单移动平均线）
- ATR（真实波动幅度均值）
- BOLL（布林带：upper/lower/mid）

预期效果：4 个缺失特征生效，特征维度从 17 → 21，特别是 `ma_bull_alignment_days` 和 `boll_width` 可能显著提升特征分离度。

### 优先级 P1：阈值回调实验

如果补齐指标后 Precision 仍不足，可尝试中间阈值：
- main_sh: 0.60（当前 0.80 太严，原版 0.43 太松）
- chinext: 0.80（当前 1.20 太严，原版 0.54 太松）
- 目标正样本比：3-4%（当前 1.2% 太少，原版 6.2% 够用）

### 优先级 P2：特征工程深化

- 特征交互：bias_ma60 × vol_breakout_ratio
- 市场状态过滤：大盘趋势作为上下文特征
- 板块独立模型：创业板/科创板单独训练
