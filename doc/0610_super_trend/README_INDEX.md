## 这个项目在做什么

用机器学习（LightGBM 模型）从 A 股 5000 只股票中，自动找出即将进入"超级主升浪"（短期内暴涨 50%+）的股票。

**核心流程**：

```
第一步：扫描全市场，找到所有"异动日"（某天涨幅>3% 或放量>1.5倍）
第二步：回看每个异动日后 22 天的表现，标注结果（涨了多少 = MFE，跌了多少 = MAE）
第三步：根据结果分三类：死水(0)、普通强势(1)、超级主升(2)
第四步：提取异动当天的技术特征（均线、量能、位置等 25 个指标）
第五步：用 LightGBM 模型学习"什么特征组合 → 对应什么结果"
第六步：模型输出概率，取概率最高的 Top N 作为买入信号
```

**数据来源**：本地通达信软件的 .day 二进制文件，包含 A 股 2020-2026 年的日线数据。

### 阶段零：策略起源（为什么要做这个项目）

项目起源于对一只股票"中船特气(688146)"走势图的观察——它在短期内暴涨数倍，但现有的交易系统（抄底型，10% 止盈）完全无法捕捉这类行情。于是决定开发一套专门的"动能突破"策略。

| 文件 | 具体内容 |
|------|---------|
| `super_trend_after.md` | 分析中船特气暴涨后的走势截图，指出它沿着 5 日均线单边拉升，现有"左侧抄底"系统会在涨 10% 时就被止盈卖飞，需要全新的"右侧追涨"策略 |
| `super_trend_before.md` | 分析暴涨前夜的微观图，发现爆发前不是典型的"突破"形态，而是"先挖坑洗盘再拉升"——这个模式可以转化为量化信号 |
| `super_trend_hour.md` | 用 60 分钟 K 线图更细致地观察"挖坑-吸筹-点火"过程，划分出 4 个阶段，每个阶段都可以提取为特征 |

### 阶段二：异动扫描与 EDA 分析（数据告诉我们要找什么）

EDA = Exploratory Data Analysis（探索性数据分析）。这一步不急着训练模型，而是先收集全市场所有"异动日"的数据，看它们的统计分布，用数据本身来定义什么是"超级主升浪"。

**核心发现**（在 `super_trend_eda_driven_params_update.md` 中）：
- 扫描了 **1,336,368 个异动日**，覆盖 5413 只股票
- 异动后 22 天的最高涨幅(MFE)中位数只有 10%，P95 才是 51%——只有前 5% 的异动才算"超级主升"
- 不同板块差异很大：主板(10%涨跌幅)的 P95 是 43%，创业板(20%)是 54%，北交所(30%)是 106%
- 颠覆性发现：高位异动(股价已在历史高位 80%+)的爆发力反而比底部异动更强

### 阶段四：三方 AI Review 与架构大改革（发现问题根源）

当训练结果不达标时(Precision 只有 33%)，请三个 AI(GPT/Gemini/Grok)同时审查，形成了关键共识。

**核心发现**：
1. **Label Gap（标签断层）**：原来只分正/负两类，把中间层(涨 10-50% 的股票)全部丢弃。模型不知道"普通强势股"长什么样
2. **T0 偏晚**：异动触发后向前回溯 T0 时门槛太高(5%/2x)，导致 T0 锁定在已经涨了很多的那天
3. **特征同质化**：缺少"相对强度"类特征(个股跑赢大盘多少)

**解决方案**：三分类标签 + 级联双模型

| 文件 | 具体内容 |
|------|---------|
| `super_trend_gpt_review.md` | GPT 的审查：指出瓶颈不在模型而在标签定义——把"涨 10-50% 的普通股"全部扔掉，导致模型学不到"强"和"更强"的区别 |
| `super_trend_gemini_confirm.md` | Gemini 确认 GPT 的判断：Label Gap 确实是 Precision 低下的元凶，同意三分类+级联方案 |
| `super_trend_gemini_adv.md` | Gemini 进阶分析：通过数据确诊 T0 截取过晚——正样本的 RSI 均值 69.3(已超买)、偏离 60 日均线 15.6%，说明 T0 在主升浪中途而非起点 |
| `super_trend_cascade_reform_report.md` | **改造方案报告**：(1)三分类 Label 0/1/2 (2)级联模型 Gate(过滤死水) + Precision(识别超级主升) (3)新增 RS20 等结构特征 (4)MA 体系修正 |
| `super_trend_casecade_reform_report_review_gpt.md` | GPT 审查改造方案：方向 90 分，但 4 处必改——(1)概率校准(Platt Scaling) (2)RS20 相对强度特征 (3)真正补 MA10/MA20 (4)Label2 比例可能偏低 |
| `super_trend_grok_experiment_report.md` | Grok 审查的对照实验：用 Grok 建议的"翻倍阈值"训练 vs 原版，结果 AUC 提升但 Precision 几乎不变，证明问题不在阈值 |
| `super_trend_scan_grok_review.md` | Grok 审查扫描器：确认正样本标签过于宽松是最致命问题 |

## 最终实验结果（截至 2026-06-12）

**数据规模**：1,331,523 个异动日样本，25 个特征，覆盖 2020-2026 年

**标签分布**：
- Label 0（死水，22天最高涨幅<10%）：51%
- Label 1（普通强势，10%-50%）：46%
- Label 2（超级主升，>50%）：3%

**模型表现对比**：

| 指标 | 单模型(2 vs 0+1) | 级联(Gate+Precision) |
|------|-----------------|---------------------|
| 交叉验证 AUC | 0.68 | 0.82 |
| 测试集 AUC | 0.68 | 0.83 |
| Top 50 精确率 | 14% | — |
| Top 200 精确率 | 20% | — |

**Top 5 特征**：bias_ma60(偏离60日均线程度)、vol_breakout_ratio(放量倍数)、t0_close(股价)、bias_ma20、price_position_120d(120天价格位置)

**实盘评估**：
- 20% 精确率意味着每 5 个信号中 1 个是真主升浪
- 理论正期望(+3.6%/笔)，但需扣除交易成本和执行损耗
- **适合作为选股辅助**（从 5000 只缩窄到 200 只候选），不建议全自动交易
- 2023-2024 熊市期间模型基本失效，需配合大盘环境过滤

## 下一步方向

1. **大盘环境过滤器（优先级最高）**：当大盘处于下跌趋势时(MA20<MA60)自动关闭信号，预计整体精确率从 20% 提升到 25-30%
2. **更细粒度的标签**：将 Label 2 拆分为"刚过线主升"(50-80%)和"超级牛股"(>80%)
3. **引入新维度特征**：市值因子、行业板块动量、资金流向等当前技术特征体系之外的信号
