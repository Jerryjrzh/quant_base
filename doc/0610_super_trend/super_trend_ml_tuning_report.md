# Super Trend ML 调优全流程报告

> 时间线：2026-06-10 ~ 2026-06-11  
> 模型：LightGBM 二分类（主升浪预测）  
> 数据：723,693 条异常日样本（正样本 45,294 / 6.23%，负样本 678,399）

---

## 一、问题背景

### 1.1 策略目标
在全市场 A 股日线上，识别"异常日"后 22 个交易日内的主升浪机会（MFE ≥ 板块阈值且 MAE ≥ -25%）。

### 1.2 数据流水线
```
全市场 .day 文件 → 前复权 → 异常触发（日涨幅≥3% OR 量比≥1.5）
    → 22日 MFE/MAE 评估 → 金字塔标签（top 5% 正 / bottom 50% 负 / 中间丢弃）
    → 60日回溯特征提取 → episodes_*.pkl → super_trend_training_data.csv
```

### 1.3 特征体系（13 维）
| 特征 | 说明 |
|------|------|
| t0_close / t0_open / t0_high / t0_low / t0_volume | T0 日价格与成交量 |
| t0_rsi / t0_macd | T0 日技术指标 |
| price_rebound_from_pit | 价格从低点反弹幅度 |
| rsi_explosion_force | RSI 爆发力 |
| macd_pit_depth | MACD 底背离深度 |
| days_below_ma30 | 价格低于 MA30 的天数 |
| vol_dryup_count | 缩量天数 |
| days_underwater | 价格在水下的天数 |
| is_extreme_volume_dry | 是否极度缩量 |

## 三、Attempt 4 详细分析

### 3.1 时序交叉验证

| Fold | 训练样本 | 验证样本 | AUC | 树数 |

| 5 | 603,078 | 120,615 | 0.6864 | 350 |

- Fold3 AUC 达 0.805，说明在某些市场周期（如趋势性牛市阶段）信号较强
- Fold4 AUC 仅 0.624，说明震荡/下行周期模型区分力较弱
- 整体 AUC 0.697 显著优于随机，模型具备排序能力

### 3.2 预测概率分布

```
min=0.0079, max=0.9621, mean=0.1620, median=0.1363
P10=0.059  P25=0.089  P50=0.136  P75=0.207  P90=0.300  P95=0.369  P99=0.525
正样本平均概率: 0.2352
负样本平均概率: 0.1573
分离度: 0.078 (绝对差)
```

**诊断**：模型输出概率整体偏低（中位数 0.136），正负样本概率差仅 0.078。说明特征信号弱，模型虽有排序能力但无法产生高置信度预测。

## 四、问题根因与修复时间线

| 轮次 | 根因 | 修复措施 |
|------|------|----------|
| A0 | 旧 pkl 污染导致 15.8% 正样本 | scanner 启动时自动清理旧文件 |
| A1 | spw 硬编码 3.0，与实际 6.23% 不匹配 | 改为动态计算 `neg_count / pos_count` |
| A2 | spw=14.9 全比率过大，首棵树 logloss 过冲 | 改为平方根缩放 `√(neg/pos)` = 3.86 |
| A3 | lr=0.05 + logloss 早停仍过冲 | 降低 lr 至 0.01，切换 AUC 指标 |
| **A4** | **✅ 已修复** | **lr=0.01 + AUC + 1000 round + 100 patience** |

## 六、后续优化方向

### 优先级 P0：特征工程
1. **增加均线系统特征**：MA5/MA10/MA20/MA60 排列状态、乖离率
2. **增加形态特征**：底部形态识别（W底/头肩底）、突破前缩量天数
3. **增加市场特征**：板块联动强度、大盘趋势状态（牛熊过滤器）
4. **增加波动率特征**：ATR 百分位、布林带宽度、历史波动率
5. **特征交互**：RSI × 量比、MACD 金叉 × 均线排列

### 优先级 P1：模型策略
1. **特征筛选**：移除分离度 < 0.05σ 的弱特征，减少噪声
2. **两阶段模型**：先用宽松阈值训练粗筛模型，再用高阈值训练精选模型
3. **降低预测阈值**：将触发阈值从 0.65 降至 0.40-0.50，结合其他规则二次过滤
4. **集成学习**：多模型投票（LightGBM + XGBoost + CatBoost）

### 优先级 P2：数据策略
1. **市场状态分层**：分牛市/熊市/震荡市分别训练
2. **板块独立模型**：创业板/科创板波动大，可独立训练
3. **时间窗口调整**：尝试 10 日/15 日/30 日评估窗口
