### 🚨 强烈建议补充：极端异常值（脏数据）过滤

在 A 股的历史日线数据中（特别是从本地 TDX 读取的数据），最容易出现一种致命的“脏数据”： **除权除息导致的未复权价格断层** 。

如果一只股票 10 送 10，第二天价格会直接“腰斩”，或者因为数据接口的问题突然暴涨 1000%。这种数据如果没有被清洗掉，会严重干扰你的均值和分位数计算（比如某个脏数据的 MFE 是 2000%，会把整个分位数拉高）。

**修改建议：** 在 `load_data()` 函数返回之前，加上两行过滤逻辑，把由于停牌或复权错误导致的极端数据剔除。

**Python**

```
def load_data():
    if not os.path.exists(INPUT_PATH):
        raise FileNotFoundError(...)
    df = pd.read_csv(INPUT_PATH)
  
    # === 新增：去噪与异常值清洗 ===
    initial_len = len(df)
    # 1. 过滤完全死水（没有涨跌幅的停牌/一字板）
    df = df[(df['future_mfe_22d'] > 0) | (df['future_mae_22d'] < 0)]
    # 2. 过滤极端暴涨异常值（比如 22 天涨幅超过 500% 的极小概率事件，多为未复权数据错误）
    df = df[df['future_mfe_22d'] <= 5.0]
  
    clean_len = len(df)
    print(f"数据清洗: 移除了 {initial_len - clean_len} 条异常数据。")
    # ============================
  
    print(f"加载异动数据: {len(df)} 条, {df['stock_code'].nunique()} 只股票")
    # ...
    return df
```

### ✅ 脚本亮点 Review（为何它能直接用于实战）

1. **`analyze_mfe_distribution` (爆发力锚定)：**
   直接看 P95 和 P97 的数值。如果你发现 P95 只有 45%，那就说明“22 天翻倍”在 A 股是万中无一的奇迹，你需要把目标务实地调降到 45% 左右。**让数据来教我们做人，而不是我们去教市场做事。**
2. **`analyze_position_impact` (位置决定性质)：**
   这个分箱（Bins）设计非常精准。你大概率会看到：深坑底部 (<20%) 的异动，其 `prob_50` (涨幅超50%的概率) 会显著高于高位区域。这将直接证明我们策略“抄底起爆点”的理论有效性。
3. **`analyze_mae_distribution` (回撤心理学)：**
   注意，你的 MAE 是负数。所以 `P01` 代表的是 **极端恶劣的回撤** （比如 -40%），而 `P50` 是 **中位数回撤** 。你可以根据 P25 或 P50 的数值，来决定你回测系统（Scheme T）里的止损线到底该设在跌破几日均线。
4. **无缝对接后续训练：**
   `derive_thresholds` 打印出来的建议参数，你可以直接复制、粘贴回你的 `super_trend_scanner_v1.py` 和 ML Trainer 里，形成完美的闭环。
