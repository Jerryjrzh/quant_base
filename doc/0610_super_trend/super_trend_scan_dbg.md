你的这个直觉非常牛，这才是真正专业量化投研的正确路径！拍脑袋定参数（比如硬编码的 4% 或 100%）往往会陷入经验主义的盲区。不同市场环境（牛市/熊市）和不同板块（主板 10% 涨跌幅限制 vs 创业板/北交所 20%、30% 涨跌幅）的波动率天差地别，4% 的单日涨幅在某些极度活跃的板块里确实只是日常的白噪音。

另外， **位置决定性质** 。一个 4% 的涨幅如果出现在长期阴跌的深坑底部，和出现在连续大涨后的高位，其代表的资金意图是完全不同的。如果不加区分地使用全局绝对数值去一刀切，很容易把真正有价值的底部试盘动作给漏掉。

先做数据探索（EDA，Exploratory Data Analysis），让数据自己开口说话，然后再倒推阈值，这是最科学的做法。

我们可以分三步来落实这个统计分析计划：

### 第一步：将扫描器降级为“全量异动抽风机”

暂时放弃在扫描阶段给样本打“正/负”标签的执念。把 `super_trend_scanner_v1.py` 里的过滤条件降到极低，只要有 **放量或者小幅异动** ，全部无脑落盘。

修改建议：

* **触发条件：** 只要 `daily_gain >= 0.03`（单日涨幅超3%） 或者 `volume_ratio >= 1.5`（量比超1.5倍），不管它未来是涨是跌，全记下来。
* **记录字段：** 记录下它的 `t0_date`、`板块类型`（主板/创业板/北交所）、`所处位置`（比如 T0 距离过去 120 天最低点的涨幅），以及未来的 `mfe_22d`（未来22天最高收益）、`mae_22d`（未来22天最大回撤）。

### 第二步：运行分布统计与分位数分析

拿着这个包含了全市场十几万次“异动”的庞大 CSV，跑一个简单的 Python 统计脚本，看看真实的分布情况。

import pandas as pd
import numpy as np

# 假设 df 是你跑出来的全量异动数据
# df = pd.read_csv('all_market_anomalies.csv')

def analyze_distributions(df):
    print("=== 全市场异动后未来 22 天最高涨幅 (MFE) 分位数 ===")
    mfe_quantiles = df['future_mfe'].quantile([0.5, 0.75, 0.90, 0.95, 0.99])
    print(mfe_quantiles.to_string())
    # 如果 99% 的分位数才只有 0.60（60%涨幅），那说明“1个月翻倍”在你的数据池里几乎不存在，阈值就得定在 0.60。
  
    print("\n=== 分板块的单日异动涨幅中位数 ===")
    # 假设你从代码前缀衍生了 market_type 字段
    if 'market_type' in df.columns:
        print(df.groupby('market_type')['daily_gain'].median())

    print("\n=== 底部异动 vs 高位异动的爆发力对比 ===")
    # 根据历史位置分层统计
    # 假设 'position_from_bottom' 是 T0 收盘价 / 过去120天最低价 - 1
    if 'position_from_bottom' in df.columns:

        print(f"底部区域异动，未来涨幅突破 30% 的概率: {(bottom_anomalies['future_mfe'] > 0.3).mean():.2%}")
        print(f"高位区域异动，未来涨幅突破 30% 的概率: {(high_anomalies['future_mfe'] > 0.3).mean():.2%}")

### 第三步：根据“金字塔法则”倒推阈值

等统计结果出来后，参数的设定就变得非常清晰了：

1. **极品正样本（Top 1% - 5%）：** 取 `future_mfe` 分位数的最高的那一小撮作为主升浪标准。
2. **绝对负样本（Bottom 70%）：** 那些连中位数都没跑赢的异动，就是彻头彻尾的假突破/骗炮。
3. **模糊地带（中间层）：** 直接在训练时丢弃，不要让这些“温吞水”行情污染模型的判断边界，我们只要极致的黑与白。
