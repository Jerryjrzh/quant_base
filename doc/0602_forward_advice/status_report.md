## 2. 已实现的改动

### 2.1 screenergf.py V4.4 动态定价整合
- `apply_morse_sniper_strategy()` 新增 `stock_code` 和 `end_date` 可选参数
- 当提供 stock_code 时自动调用 `backtester._generate_forward_advice_v4()` 生成场景化 ATR 定价
- 保留静态折扣作为 fallback（V4.4 失败时使用）
- 所有调用方（walk_forward、日常选股）统一享受 V4.4 定价

### 2.2 阶梯式 Trailing Stop
替代原有单一 7% 保本门槛:
```
MFE >= 7%  -> 锁定 5% 利润
MFE >= 5%  -> 锁定 3% 利润
MFE >= 3%  -> 保本 (entry * 1.01)
```
**效果**: sz000803 从 +0.83%(持仓到期) 改善为 +3.00%(止损出局)

### 2.3 每日持仓评估系统 `_evaluate_daily_position()`
- 每天调用 confluence_scorer + pattern_recognizer 评估持仓状态
- 输出: 分数、阶段、置信度、形态、风险等级、调整后的 TP/SL
- **驱动实际交易决策**: 动态修改 actual_take_profit / actual_stop_loss

### 2.4 结果输出增强
- `daily_journal` JSON 字段记录每日评估详情
- `selection_verdict` 选股合理性判定（合理/边际/失败）
- `latest_daily_journal.csv` 独立输出每日评估明细

## 3. 逐笔交易分析

### sh600331 (distribution D级)
| 版本 | 收益率 | 退出原因 |
|------|--------|---------|
| Run 1 | -0.41% | 止损出局 |

**改善机制**: 每日评估在 distribution 阶段收紧止盈(18.49->17.96)，提前锁定利润。正确改善。

### sh601872 (markup A级)
| 版本 | 收益率 | 退出原因 |
|------|--------|---------|
| Run 1 | +11.23% | 止盈出局 |
| Run 3 | +6.74% | 收紧后止盈出局 |

**问题**: BUY A级股票在 markup 阶段被 distribution 止盈收紧误伤。首日评估检测到 distribution 将止盈从 19.81 收紧到 19.01，导致过早触发。需要区分信号等级。

### sz000803 (markup A级)
| 版本 | 收益率 | 退出原因 |
|------|--------|---------|
| Run 1 | +0.83% | 持仓到期 |

**改善机制**: 阶梯式 trailing stop 在 MFE=5.7% 时锁定 3% 利润，第二天回落触发止盈。

### sz300006 (distribution D级, AVOID信号)

## 4. 已知待优化问题

### 4.1 distribution 阶段止盈收紧过度
- 当前: distribution 一律收紧到 60%
- 问题: BUY A级信号被误伤 (sh601872: 11.23% -> 6.74%)
- 建议: 区分信号等级，A级使用 80%，D级保持 60%

### 4.2 AVOID 信号过滤
- 当前: 3 笔 AVOID 信号仍被执行交易
- 建议: walk_forward 中对 AVOID 信号直接跳过或降低仓位

### 4.3 成交率
- 当前: 12 个 BUY 信号仅 6 个成交 (50%)
- 原因: V4.4 入场价偏保守，部分票次日高开直接跳过
- 建议: 可考虑对 A 级信号适当放宽入场价容忍度
