## 方案解析

### A系列: 简单延长持仓

最直接的方案 — 仅修改 time_stop_days 参数。

- **15天是甜点**: 胜率从61.9%跳至68.6% (+6.7pp)，TP翻倍 (616→1258)
- **20天PnL最高** (+99%) 但边际收益递减: 15→20天仅+7.6% PnL，却多了107笔SL
- 每延长1天约增加2%累计PnL，但SL风险线性增长

### C系列: 阶梯时间止损 (条件续持)

第7天评估: 收益 < 阈值 → 续持，≥ 阈值 → 锁定。

- **2%阈值 + 14天**: 胜率最高 (70.9%)，因为低收益 (=洗盘概率高) 的票给了更多时间
- 逻辑: 到期收益<2% ≈ 价格在入场价附近震荡 ≈ 主力洗盘 → 续持大概率拉升
- 到期收益>2% ≈ 已有一波涨幅 → 落袋为安

### CA系列: 阶梯 + 更长续持

C的改良版 — 到期低收益的票续持至15-20天。

- **3%阈值+15天**: 胜率71.1% (全方案最高)，PnL +84.2%
- **2%阈值+20天**: 胜率72.1%，但SL增加 (466 vs 379)
- 综合不如 A_15d 简洁有效

### D系列: 动态追踪止盈

到期后改为追踪止损 (从最高点回撤N%平仓)。

- **所有D方案均不如A/C**: 追踪止损被20CM票的噪音频繁触发
- 追踪5%回撤: 1597笔追踪止损，均收益仅+2.45%
- 追踪3%更差: 1637笔追踪止损，太敏感
- 追踪7%稍好: 但仍不及固定TP

## 推荐方案

### 首选: A_15d (延长至15天)

**优势**:
- 实现最简: 仅改 `time_stop_days = 7` → `15`
- 效果显著: PnL +33.4%，胜率 +6.7pp
- TP翻倍: 616 → 1258
- 风险可控: MAE从-3.57%增至-4.82% (可接受)

**代价**:
- SL增加: 89 → 387 (多298笔止损)
- 平均持仓天数: ~6天 → ~9天
- 资金周转率降低

### 备选: CA_2%_20d (最高胜率)

**优势**: 72.1%胜率，到期PnL +84.8%  
**代价**: 实现复杂 (需第7天评估逻辑)，SL 466笔  
**适合**: 追求高胜率、厌恶止损的交易风格

### 不推荐: D系列 (追踪止损)

追踪止损在20CM高波动环境中表现差，60%+的交易被追踪止损，均收益仅+2.45%。
