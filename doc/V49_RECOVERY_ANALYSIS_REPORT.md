## 4. 挽回策略建议

### 策略 1: order_timeout 强制入场 (高价值)

- **目标**: S + A tier 的 order_timeout (14 笔)
- **方法**: 挂单超时后以市价追入 (或 T+1 开盘价)
- **预期**: 单笔 EV ≈ +14.4% (future_mfe 的 50% 折扣)
- **风险**: 价格偏离 (均 +1.1%), 可能入场即亏
- **建议**: 仅对 S tier 强制执行, 偏离≤3% 时入场

### 策略 2: 动态止盈 / 移动止盈 (中等价值)

- **目标**: 101 笔遗憾单 (MFE 已达 7-10% 但未触发止盈)
- **方法**: 当 MFE 达到 7% 后, 启动移动止盈 (回撤 3% 即平仓)
- **预期**: 每笔多挽回 +2~3%, 总计 +2~3% 年化提升
- **风险**: 部分可能从 +7% 继续上涨到 +10% 止盈线

### 策略 3: 提前平仓磨底票 (防御性)

- **目标**: 持仓 ≥5 天且 MFE < 3% 的到期票
- **方法**: 第 5 天检查, 若 MFE < 3% 强制平仓
- **预期**: 减少时间成本, 释放资金给新信号
- **风险**: 可能错过后续爆发

### 策略 4: gap_abandoned 追入 (高风险)

- **目标**: 42 笔低开放弃信号
- **方法**: 开盘跌幅收窄后 (如 MAE 回到 -5% 以内) 市价追入
- **预期**: future_mfe +34%, 但 mae -11% 波动极大
- **建议**: 不建议, 风险收益比不佳

## 6. 结论

1. **order_timeout 是最大的挽回池**: 240 笔中 88.8% 后续涨幅超 10%, 但大部分是 B_GBM tier, 仅 S tier (13笔) 值得强制追入
2. **遗憾单是最容易挽回的**: 101 笔 MFE 已达 7%+ 但差一口气到止盈线, 引入移动止盈机制即可部分挽回
3. **到期交易本身并非亏损**: 72.2% 胜率, 均收益 +2.9%, 只是收益率不如止盈单
4. **gap_abandoned 不建议挽回**: 虽然后续走势好, 但入场时 MAE 太深 (-11%), 风险不可控
