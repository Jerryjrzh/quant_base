基础分 = 60, 各加分/减分项作用:

| 路径 | 加减分 | 最终分 | 实际 PF | 加分方向是否正确 |

| T1_L + T1_B (长下影+下影) | +20+15? | 95 | 2.63 | **最负面** (PF 仅为基准的 44%) |

**结论**: screenergf.py 中的莫尔斯加分项**全部反向**。当前系统默认"长下影+下影线"是最佳形态 (加到 95),
但实盘数据证明这是**最差形态** (PF=2.63)。无特征触发的"平庸股"反而最赚钱 (PF=5.96)。

## 三、月度 regime 拆分 (验证稳定性)

| 月份 | 60分 | 70分 | 75分 | 85分 | 95分 | 全月均收益 |

| 2025-09 | 0 | 0 | 0 | 22 | 444 | +1.31% |
| 2025-10 | 0 | 0 | 0 | 0 | 57 | +0.57% |

### regime 解读

- **7-8 月**: 60 分信号大量触发 (3194 + 380 = 3574 笔), 市场处于**高频活跃**状态
- **9 月**: 60 分信号**完全消失** (0 笔), 仅 85/95 分通过, 市场转向冷门
- **10 月**: 仅 57 笔 95 分 (采样不完整, 可能月末)

**结论**: score=60 不是稳定的选股信号, 而是**市场环境指示器**。
当 60 分信号大量出现时, 策略整体赚钱; 当 60 分信号消失时, 策略被迫只做高分股, 收益下降。

## 七、落地改进方案

### 方案 A: 反转加分项 (推荐)

根据本测试, `screenergf.py` 第 804-815 行的加减分应**全部反转**:

```python
# 当前 (反向):
if T1_B: score += 15        # 下影线加分 ❌
if T1_D: score += 10        # 下跌日加分 ❌
if T1_L and T1_B: score += 20  # 长下影加分 ❌

# 修正后 (按实测方向):
if T1_B: score -= 15        # 下影线扣分 ✓
if T1_D: score -= 10        # 下跌日扣分 ✓
if T1_L and T1_B: score -= 20  # 长下影扣分 ✓
```

**预期效果**: 原本 score=60 的平庸股会被**提权到 75-95 分**,
原本 score=95 的"明星股"会被**降级到 45-65 分** (低于 85 门槛被淘汰)。
这样 85 分门槛就能真正筛出 alpha。

### 方案 B: 保持门槛, 新增过滤

在 85+ 分中, 额外过滤掉 `T1_L=1 && T1_B=1` 的组合 (95 分组),
因为这组的 PF=2.63 是 85+ 分中最差的。

### 方案 C: 引入 regime 过滤

监控 score=60 的信号数量 (滚动 5 日均值):
- 当 60 分信号 > 50 笔/日: 市场处于强势 regime, 策略放量运行
- 当 60 分信号 < 10 笔/日: 市场转冷门, 策略减仓或暂停

### 优先级

1. **方案 A (反转加分项)**: 根本性修复, 必须实施
2. **方案 B (过滤 95 分)**: 快速止血, 可立即上线
3. **方案 C (regime 过滤)**: 锦上添花, 可与 1+2 叠加
