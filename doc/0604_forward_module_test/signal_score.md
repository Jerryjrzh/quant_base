 ▪ 核心结论                                                                                       
                                                                                                   
   1. 前两条信号验证                                                                               
   ┌───────────────────────┬──────────┬────────┬────────┬─────────────┐                            
   │ 信号                  │ 评分     │ MFE    │ MAE    │ 交易结果    │                            
   ├───────────────────────┼──────────┼────────┼────────┼─────────────┤                            
   │ sh688501 (2025-01-02) │ 95 (A级) │ +0.29% │ -8.76% │ 亏损 -2.14% │                            
   │ sh688271 (2025-01-02) │ 95 (C级) │ +2.97% │ -7.15% │ 微赚 +1.45% │                            
   └───────────────────────┴──────────┴────────┴────────┴─────────────┘                            
   MFE/MAE 手动计算与 CSV 完全吻合。但两条都在"股灾暴跌"日发出信号，说明大盘环境过滤不够严格。     
                                                                                                   
   2. 评分系统存在严重问题                                                                         
                                                                                                   
   98.2% 的信号都是 95 分（策略 base=95），评分几乎没有区分度：                                    
   ┌──────┬─────────┬───────┬─────────┬──────────┬────────┐                                        
   │ 评分 │ 信号数  │ 占比  │ 平均PnL │ 盈利因子 │ 止盈率 │                                        
   ├──────┼─────────┼───────┼─────────┼──────────┼────────┤                                        
   │ 85   │ 2,994   │ 0.7%  │ 0.74%   │ 1.56     │ 8.4%   │                                        
   │ 90   │ 198     │ 0.05% │ 0.59%   │ 1.43     │ 8.6%   │                                        
   │ 95   │ 407,364 │ 98.3% │ 0.56%   │ 1.79     │ 2.6%   │                                        
   │ 100  │ 64      │ 0.02% │ 0.17%   │ 1.11     │ 6.2%   │                                        
   │ 110  │ 3,333   │ 0.8%  │ 0.36%   │ 1.32     │ 4.3%   │                                        
   │ 115  │ 489     │ 0.1%  │ 0.07%   │ 1.06     │ 2.2%   │                                        
   └──────┴─────────┴───────┴─────────┴──────────┴────────┘                                        
   反直觉发现：85分信号表现最好，115分信号表现最差。 评分系统对收益的预测能力是反向的。            
                                                                                                   
   原因：85 分信号因被扣分（T1_D/T1_L 等看跌因子），挂单价更低，风险收益比反而更好；110-115        
   分信号因 M15_U 等看涨因子加分，入场价偏高，追高被套概率更大。                                   
                                                                                                   
   3. 85 分阈值无实际过滤效果                                                                      
                                                                                                   
   由于 98.2% 信号 = 95 分，阈值设 70/85/95 的回测结果几乎完全一样（411K-414K 笔交易，胜率         
   62.2%，PF 1.78）。85 分不是有效的分水岭。                                                       
                                                                                                   
   4. 真正的差异化因子是板块                                                                       
   ┌──────┬───────┬─────────┬──────────┐                                                           
   │ 板块 │ 胜率  │ 平均PnL │ 盈利因子 │                                                           
   ├──────┼───────┼─────────┼──────────┤                                                           
   │ 10CM │ 63.4% │ 0.61%   │ 1.97     │                                                           
   │ 20CM │ 60.7% │ 0.49%   │ 1.57     │                                                           
   │ 30CM │ 56.5% │ 0.47%   │ 1.48     │                                                           
   └──────┴───────┴─────────┴──────────┘                                                           
   10CM 板块的交易质量显著优于 20CM/30CM。                                                         
                                                                                                   
   5. 退出策略问题：时间衰减过于激进                                                               
                                                                                                   
   - 时间衰减平仓: 56.5% — 超过一半的交易因动能不足被提前平掉                                      
   - 止损出局: 37.3%                                                                               
   - 止盈成功: 仅 2.6% — 极少交易能吃到目标利润                                                    
                                                                                                   
   建议方向                                                                                        
                                                                                                   
   1. 评分系统需要重新校准 — base 95 分太高，应降低 base 并让因子加减分产生更大差异                
   2. 85 分作为阈值没有意义 — 真正有效的过滤维度是板块类型和大盘环境                               
   3. 时间衰减退出过于激进 — 56.5% 的交易被提前平仓，应考虑放宽 MFE 门槛                           
   4. 板块差异化策略 — 10CM 用更宽的入场条件 + 严格止盈，20CM/30CM 需要更保守
