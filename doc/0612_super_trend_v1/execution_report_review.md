## 三、接下来的任务（两个必须执行，一个可选）

### 任务一：止损策略优化 + 真实回测重跑（P0，立即执行）

**目标**：将真实回测胜率提升到 40-50%，最大回撤控制在 25% 以内，年化收益转正。

**方案（按推荐顺序）**：

**方案A：放宽固定止损至 -15%**
- 最简单，立即生效。
- 逻辑：异动股日均波动 5-8%，22天窗口内 -8% 几乎是必然触达的噪声。-15% 过滤掉噪声，只保留真正的反向破位。

**方案B：ATR 动态止损（推荐优先实施）**
- 止损线 = T+1开盘价 - N × ATR(20)。
- 高波动股自动放宽止损，低波动股收紧，让每只股票的止损阈值适配自身波动特征。
- 建议 N 从 2.0 开始测试，搜索 1.5~3.0 的最优值。

**方案C：追踪止损（可选叠加）**
- 从持仓期间的最高浮盈回撤 X% 时止盈，替代固定止盈。
- 例如：浮盈达 15% 后，启动追踪止损 8%，股价从高点回落 8% 即卖出。

**实施步骤**：
1. 修改 `real_path_backtester.py`，新增 ATR 止损和追踪止损逻辑。
2. 在验证集（2024年数据）上做网格搜索，找出最优的止损/止盈参数组合。
3. 用最优参数在测试集（2025-2026）上重新运行回测。
4. 输出完整的对比表（方案A/B/C vs 当前）。

**验收案例**：

选择之前止损出局但最终 MFE 很高的案例，验证新止损策略是否能让它们转化为盈利：

例如 `sz002958`（之前孪生对中 MFE 78.4% 但排名被低估的那只）：
- 旧止损：T+4 天即触发 -8%，收益 -8.30%，持仓 4.5 天。
- 假设其真实路径：T+4 最低跌到 -9%，但随后回升，T+15 达到 +50%。
- **-15% 止损预期结果**：不触发，最终在止盈或持有到期时获利。
- **ATR 止损预期结果**：若 ATR(20)=5%，止损线=-10%，同样不触发，转为盈利。

**验收标准**：
- 胜率 ≥ 40%。
- 最大回撤 < 25%。
- 年化收益 > 0。
- 至少 3 个上述“旧止损误杀”案例被修复为盈利。
