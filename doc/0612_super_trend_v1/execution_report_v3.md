## 0. 验证目标

`execution_report_review.md` 定义了三个止损方案：
- **方案A**: 放宽固定止损至 -12% ~ -15%
- **方案B**: ATR 动态止损 (止损线 = -N × ATR(20))
- **方案C**: 追踪止损 (浮盈达 X% 后从最高点回撤 Y% 出场)

本次验证在全测试期 (2025-02-21 ~ 2026-03-11) 上对三方案完整参数网格（108 组）逐一回测，确认是否存在可用参数。

## 4. 核心结论

### 108/108 组参数全部亏损 — 止损策略不是根因

**所有参数组合的年化收益均为负（-48% ~ -100%），最大回撤均超过 -86%。** 这意味着无论采用何种出场规则（固定止损、ATR 止损、追踪止损），选股信号在测试期都是负期望。

### 关键证据

| 观察 | 含义 |
|------|------|
| 108 组全部亏损 | 止损/止盈参数不是问题所在 |
| 止损越宽松（-20%、ATR N=3.0），持有到期占比越高，但仍亏损 | 22 天持有期末的收盘价本身就是负的 |
| 方案C 胜率最高（~40-60%），但平均收益仍为负 | 赢的次数多但幅度小，亏的次数少但幅度大 |
| 方案A 盈亏比最高（2.5-3.2），但胜率太低（17-31%） | 正期望需要 胜率 × 盈亏比 > 1，当前远不够 |

### 与 execution_report_v2 的对比

|------|------------|--------------|
| 排序模型区分力 | 孪生对 100% | 孪生对区分力存在，但未转化为测试期正期望 |

| 年化收益 | - | **-99%+，策略完全不可用** |

## 5. 根因分析

### 问题定位：选股信号在测试期无正期望

精排模型的排序能力（孪生对 A>B 100%）在测试期未能产生正期望收益。可能原因：

1. **训练集前视偏差/标签泄漏**: 训练期排序效果好可能因为标签构造时使用了未来信息，而测试期标签是真实未来数据
2. **过拟合**: 精排模型在训练集的 V2 时序特征上学到了噪声而非结构性信号
3. **测试期市场环境**: 2025-02 ~ 2026-03 可能为系统性下行/震荡市，所有异动股策略均失效
4. **两阶段排序偏差**: 粗排模型（含 boll_width）可能在测试期就选错了候选池，精排无从修正

## 6. 下一步建议

### 优先级 P0: 确认选股信号本身是否有效

**验证方法**: 不看任何出场规则，只看精排 Top 20 在第 22 天的 raw return（买入价 = T+1 开盘，卖出价 = 第 22 天收盘）。

```
如果 Top 20 的 raw return 均值 > 全量基线 → 选股有效，问题在出场规则
如果 Top 20 的 raw return 均值 ≤ 全量基线 → 选股无效，需回退到模型训练阶段
```

### 优先级 P1: 检查训练标签

- 确认 `future_mfe` 的计算是否使用了 T+1 之后的数据
- 检查训练集/测试集的时间切分是否严格（80/20 split 是否存在数据泄漏）

### 优先级 P2: 检查测试期市场环境

- 统计 2025-02 ~ 2026-03 的大盘（沪深300）涨跌幅、波动率
- 与训练期（2020-2024）对比，确认是否为异常市场环境
