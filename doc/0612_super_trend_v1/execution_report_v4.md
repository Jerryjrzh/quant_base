## 0. 一句话结论

**精排模型能选出 MFE 比全量高 58.7% 的股票（选股有效），但这些股票在 22 天持有期内"冲高回落"——MFE 均值 +20%，第 22 天收盘均值 -3.7%。模型捕捉的是已经发生的动量，而非未来趋势的起点。**

## 3. 根因诊断: 动量尾部信号

### 模型选的是什么股票？

精排模型的 Top 1 特征 `price_rebound_from_pit`（从坑底反弹力度）和其他 V2 特征（均线束发散、排名稳定性、洗盘深度），本质上在识别 **已经发生过一轮上涨的股票**：

```
模型信号触发时的股票状态:
  坑底 → 反弹 → 均线束发散 → 排名上升 → 信号触发 → 买入
                                                    ↑
                                               此时已涨了 15-30%
```

### 为什么 MFE +20% 但持有 -3.7%？

这些股票在被模型选中时，主升浪的 **大部分涨幅已经实现**。买入后的价格路径是:

1. **惯性冲高** (几天内达到 +20% MFE) — 主升浪尾部
2. **动量衰竭** — 没有新的买盘接力
3. **均值回归** — 获利盘卖出，价格回落
4. **第 22 天收盘 -3.7%** — 从峰值回吐了 24 个百分点

### 为什么止损优化无效？

因为问题不是"止损太紧被误杀"，而是:
- 即使**完全不设止损**，持有 22 天也是亏的 (-3.7%)
- 被止损踢出的股票，MFE 确实有 +10~15%，但那是**止损之后才实现的涨幅**
- 即使给它们更多时间，最终也会回吐（22 天后仍是负的）

## 7. 可行方向 (按可行性排序)

### 方向 1: 短期持有 + 快速止盈 (最匹配当前信号特征)

**逻辑**: 既然 MFE 在前几天实现 (+20%)，第 22 天回落到 -3.7%，那就在冲高时离场。

```
T+1 买入 → 持有 3-5 天 → 第 5 天收盘卖出 (固定时间退出)
```

验证方法: 在 `pure_mfe_analysis.csv` 的 raw paths 上，计算:
- 持有 3 天收益
- 持有 5 天收益
- 持有 10 天收益
- 找到收益最大化的最优持有天数

### 方向 2: 追踪止盈 (不预测时间，跟随价格)

```
无止损 (或极宽止损 -30%)
浮盈 > 10% 后启动追踪: 从最高点回撤 5% 即卖出
```

本质: 在冲高回落的拐点自动离场，捕获 MFE 的一部分。

### 方向 3: 重新定义训练标签

**当前**: `future_mfe` = 22 天内最大涨幅 → 模型学到的是"谁会冲高"，而非"谁会涨到结尾"

**修改**: 用以下标签重新训练:
- `future_return_5d`: 5 天后收益 (匹配短期持有)
- `future_mfe_5d`: 5 天内最大涨幅
- `risk_adjusted_return`: MFE / max_drawdown (奖励冲高且不回落的)

### 方向 4: 延迟入场 (等回调后买入)

```
信号触发后不立即买入
等待 2-3 天内出现回调 (如 close < T+1 close)
回调企稳后入场 → 减少初始回撤 → 提高 MFE 捕获率
```

### 推荐优先级

1. **先验证方向 1** (最短路径): 计算不同持有天数的收益曲线，确认是否存在正期望窗口
2. **再尝试方向 3** (根本解决): 用短期收益标签重训模型，让模型直接预测"谁在未来 5 天涨"
3. 方向 2 和 4 作为辅助叠加
