### 5.3 挂单超时根因

挂单价普遍设在 **7 天最低点以下**（区间位置为负值），导致：
- T+1 开盘价高于挂单价，直接跳过未成交
- 股票随后大幅上涨，错失主升浪

**本质问题**: 挂单价过于保守，追求"完美低价"但牺牲了成交率。

### 6.2 优化建议 (按优先级)

#### 🔴 P0: 挂单定价优化 (预期收益提升最大)

**现状**: 挂单价 = V4.4 entry (通常 T0 收盘 ×0.95~0.96)
**问题**: 开盘跳空高开后挂单价远低于市价，无法成交

**建议方案**:
```
方案 A: 挂单价 = max(V4.4_entry, T0_收盘 × 0.98)
方案 B: 挂单价 = T+1_开盘价 × 0.99 (竞价成交)
方案 C: 挂单价 = T0_收盘 × 0.97 (折中)
```

**预期效果**: 若 17 笔中 50% 成交，额外收益 = 17 × 50% × 18.8% = +160% 总收益

#### 🟡 P1: 保本线前置

**现状**: 浮盈 ≥5% 才触发保本 (止损上移至成本+0.5%)
**问题**: MFE 在 5%~8% 区间的交易，等保本线激活时已开始回吐

**建议**:
```
保本触发: 浮盈 ≥ 3% (原 5%)
保底线:   成本 + 0.5%
```

**预期效果**: sh688403/sz300695/sz301517 等交易收益可提升 2~4pp

#### 🟡 P2: 入场位置过滤

**现状**: 入场位置 >50% 的 6 笔全部亏损
**建议**: 若 `trigger_buy > 近7天_high × 0.95`，放弃该信号

#### 🟢 P3: 追踪止盈收紧

**现状**: 允许回吐 MFE 的 40%
**建议**: 收紧至回吐 30%，提升止盈效率

## 附录: 数据源与计算方法

- **数据来源**: `backend/latest_walk_forward.csv` (回测日期 2026-04-01)
- **入场位置**: `(trigger_buy - 回测底) / (回测顶 - 回测底)`
- **出场位置**: `(exit_price - 回测底) / (回测顶 - 回测底)`，其中 `exit_price = trigger_buy × (1 + 收益率)`
- **MFE回吐**: `(MFE - 收益率) / MFE`
- **出场效率**: `收益率 / MFE`
