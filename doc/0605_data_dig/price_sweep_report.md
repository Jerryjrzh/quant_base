## 四、入场价敏感度: 哪些场景需要更低的入场价?

### 4.1 按信号入场位置 (trigger_buy 在 7 天区间的位置)

| 入场位置 | N | 最优入场 | entry=0% EV | entry=-5% EV | 结论 |
|:---:|:---:|:---:|:---:|:---:|------|
| **低位 <30%** | 512 | **+0%** | **+3.33%** | +0.62% | 浅挂更好，直接 T0 收盘 |
| **中位 30-60%** | 68 | **-5%** | **-2.07%** | **+1.40%** | **必须深挂，浅挂亏损** |
| **高位 >60%** | 41 | **-10%** | **-2.57%** | -2.67% | 两种都亏，建议放弃 |

**这是唯一需要差异化入场价的维度。**

中位信号(30-60%):
- T0 收盘入场(EV=-2.07%)是因为这些票 T0 收盘已处于区间中段，后续波动偏向下行
- -5% 深挂后成交率提升到 75%，EV 翻正至 +1.40%

高位信号(>60%):
- 无论什么入场价都是负 EV，说明选股本身在这些位置失效
- **建议直接过滤: entry_pos > 60% 的信号不参与交易**

**结论: 除了"高位信号"外，所有子群体的最优入场价都是 T0 收盘(+0%)。** 深挂(-5%)在几乎所有场景下都大幅损害 EV，因为成交率暴跌(73%→20%)而成交后的平均收益提升不足以弥补。

## 五、实盘推荐方案

### 5.1 分层定价策略

```
if entry_pos < 0.30 (低位信号, 82% 的信号):
    入场价 = T0 收盘价 × 1.00 (直接 T0 收盘买入)
    TP = 18%, SL = -10%, 持仓 7 天

elif entry_pos 0.30~0.60 (中位信号, 11% 的信号):
    入场价 = T0 收盘价 × 0.95 (深挂 5%)
    TP = 18%, SL = -10%, 持仓 7 天

else (高位信号, 7% 的信号):
    放弃该信号
```

### 5.2 进阶: 按 markup 阶段微调

```
if v44_trend == 'markup' and v44_bias_tier == '深渊超跌':
    TP = 25%  (markup + 超跌 的利润空间更大)

if v44_bias_tier == '空头偏离':
    TP = 22%  (空头偏离层需要更宽 TP 让利润发展)
```

### 5.3 追踪止损: 保持关闭

当前回测数据明确显示追踪止损有害。如需启用，仅在以下条件使用:
- 触发门槛: MFE ≥ 5% (而非 3%)
- 锁定比例: MFE × 50% (而非 60%)
- 即便如此，EV 仍低于不追踪 (+1.91% vs +2.35%)
