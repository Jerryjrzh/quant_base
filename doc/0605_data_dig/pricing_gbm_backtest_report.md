**日期**: 2026-06-05
**数据**: `full_calendar_trades.csv` (625 信号, 2026-01~2026-05)
**模型**: `pricing_gbm_v1` (21 特征, F1=0.646, AUC=0.657)
**模拟参数**: TP=+18%, SL=-12%, 无追踪止损, 7 天持仓

**结论**: 固定浅挂的 EV (+2.187%) 略优于 GBM 自适应 (+2.050%)，差距 -0.137% (-6.3%)。

## 五、核心发现与结论

### 1. GBM 分组方向正确，但整体 EV 未超越固定浅挂

GBM 成功识别了低概率信号应深挂、高概率信号应浅挂。但中性组 (61.4% 信号) 使用 0.97 入场时，成交率 (41.9%) 显著低于浅挂 (69.3%)，导致整体 EV 被拖累。

### 2. 根本原因: 深挂成交率断崖

| 入场折扣 | 成交率 |
|:---:|:---:|
| ×0.99 (浅) | 72.0% |
| ×0.97 (中) | ~42% |
| ×0.95 (深) | 21.4% |

从 0.99 到 0.95，成交率下降 50.6 个百分点，但成交均 PnL 仅下降 0.455 个百分点。**成交率的损失远大于单价优势**。

### 3. 低概率组深挂确实更优，但样本量有限

低概率组仅 46 个信号 (7.4%)，其中深挂成交 22 笔，浅挂成交 27 笔。虽然深挂 EV (+2.374%) 高于浅挂 (+1.367%)，但对总体 EV 的贡献有限。

### 4. 实际建议

| 方案 | 适用场景 | EV |
|------|------|:---:|
| **固定浅挂 (推荐)** | 全量信号统一策略 | +2.187% |
| GBM + 仅高概率浅挂 | proba>0.7 用浅挂, 其余仍浅挂 | +2.187% (等同) |
| GBM 自适应 (当前) | 区分深/浅/中性 | +2.050% |

**最终建议**: 在全量信号上使用**固定浅挂 (×0.99)** 作为默认入场策略。GBM 的价值在于识别高概率信号 (>0.7) 可加仓/提高优先级，而非调整入场价格。

## 六、V4.7 代码实施

基于回测结论，已对以下文件进行代码修改:

### walk_forward_tester_s.py (V4.6 → V4.7)

| 变更项 | V4.6 (旧) | V4.7 (新) |
|--------|-----------|-----------|
| 入场定价 | GBM 三档: proba>0.7→×0.99, <0.3→×0.95, 其余→×0.97 | 固定浅挂 `t0_close × 0.99` |
| GBM 概率用途 | 直接决定入场价 | 仅记录到 CSV，用于信号优先级排序 |
| ma_slope 输出 | 硬编码 0.0 | 使用实际计算值 `(ma20-ma20_prev)/ma20_prev` |

### 新增 CSV 输出列 (供定价 GBM 回测)

| 列名 | 说明 | 用途 |
|------|------|------|
| `close_t0` | T0 收盘价 | GBM 特征基准价格 |
| `t1_open` | T+1 开盘价 | GBM 特征: t1_open_gap |
| `t1_high` | T+1 最高价 | GBM 特征: t1_range |
| `t1_low` | T+1 最低价 | GBM 特征: t1_low_drop (最重要, 41.5%) |
| `t1_close` | T+1 收盘价 | GBM 特征: t1_close_strength (12.6%) |
| `swing` | 7 日振幅 (max-min)/close_t0 | GBM 特征: swing (19.7%) |
| `bias_20` | 20 日乖离率 | GBM 特征: bias_20 (3.0%) |
| `ma_slope` | 20 日均线斜率 | GBM 特征: ma_slope (1.6%) |

有了这些列，`pricing_gbm_backtest.py` 可直接读取真实值，无需从 `future_7d_path` / `morse_features` 近似派生。

### pricing_gbm_backtest.py

`extract_features_from_csv()` 自动检测 CSV 版本:
- **V4.7+ CSV**: 直接读取 `close_t0`, `t1_open/high/low/close`, `swing`, `bias_20`, `ma_slope`
- **旧 CSV**: 回退到 `trigger_buy/0.95` 估算 T0 收盘，从 `future_7d_path` 派生 T1 OHLC

### calendar_batch_runner_m.py

无需修改。新增列通过 `pd.concat` + `to_csv` 自动传递到 `full_calendar_trades.csv`。
