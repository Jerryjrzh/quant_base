## 三、价格机制评估 — 入场价

### 3.1 挂单超时 — 最大的利润黑洞

| 指标 | 数值 |

| 超时信号的 future_mfe > 10% | **53.6%** (210/392) |

| 损失的潜在利润总和 | **5086%** (占总 future_mfe 的 74.8%) |

**这是系统最严重的问题: 选股对了，但钱没赚到。**

### 3.2 挂单价过低的根因

| 指标 | 数值 |
|------|:---:|
| 挂单价 < 7天最低点 | **91.6%** (359/392) |
| 挂单价到回测底的平均跳空 | +2.06% |
| T+1 开盘跳空 > 2% | 49.5% |
| T+1 开盘跳空 > 5% | 6.9% |

**根因分析:**
1. 挂单价通常设在 T0 收盘价 × 0.95~0.96 (即 V4.4 entry)
2. T+1 开盘价平均比挂单价高 2.06%，直接跳空跳过挂单价
3. 近半数信号 T+1 跳空 > 2%，挂单永远无法成交
4. 这些被错过的信号 future_mfe 中位 10.55%，92.6% 在7天内涨幅超5%

## 四、价格机制评估 — 出场价

### 4.1 止损机制的致命矛盾

| 指标 | 数值 |
|------|:---:|
| 止损出局总笔数 | 143 |
| MAE **未触及**止损线的 | **83.2%** (119/143) |
| 正收益出场的("保本线触发") | **76.9%** (110/143) |
| 正收益均值 | +2.11% |
| 这些交易的 future_mfe 中位 | **7.43%** |
| 止损后 future_mfe > 5% | **72.7%** (104/143) |
| 止损后 future_mfe > 10% | 20.3% (29/143) |
| MFE 回吐率中位 | **51.9%** |

**核心矛盾: 83.2% 的"止损"交易，实际 MAE 从未触及原始止损线。**

这意味着:
1. 大部分止损并非被"打止损"，而是被**保本线**或**追踪止损**触发
2. 76.9% 的止损交易是正收益出场(平均 +2.11%)，说明系统在小赚时就急着平仓
3. 但这些交易后续 7 天 future_mfe 中位 7.43%，104 笔(72.7%)后来涨了 5%+
4. **系统在"保护利润"的名义下，过早终止了正在发展的趋势**

### 4.2 遗憾交易分析

止损中 future_mfe > MFE + 2% 的交易(future 涨幅远超持仓期间 MFE):

| 指标 | 数值 |
|------|:---:|
| 笔数 | **80/143** (55.9%) |
| average future_mfe | 10.07% |
| average 实际 MFE | 3.79% |
| average 实际收益 | +0.50% |
| 潜在可获利润总和 | **805.93%** |

**这 80 笔交易的共同模式:**
- 持仓期间 MFE 仅 3.79% → 还没涨多少就被保本线/追踪止损打了
- 平仓后 7 天 future_mfe 达 10.07% → 主升浪在出场后才启动
- 实际收益仅 +0.50%，但如果拿住，平均可多赚 9.57%

### 4.3 MFE 捕获效率

| 交易状态 | MFE捕获率 (收益/future_mfe) | >50%占比 |
|----------|:---:|:---:|
| 止盈成功 | **71.0%** (中位 74.7%) | 90.0% |
| 止损出局 | 10.6% (中位 19.6%) | 63.6%* |

> *止损和衰减组的 >50% 是实际 MFE/future_mfe 的比值，而非收益率/future_mfe

**止盈逻辑是合理的** — 71% 的 future_mfe 捕获率，且 90% 的交易捕获了 50% 以上的涨幅。

**止损逻辑严重失效** — 仅捕获了 10.6% 的 future_mfe，55.9% 的交易被过早终止。

## 五、综合结论

### 5.1 选股引擎评价

| 维度 | 评分 | 说明 |
|------|:---:|------|
| 选股质量 | ★★★★★ | 81.4% 信号 future_mfe>5%，选股引擎非常可靠 |
| GBM 过滤 | ★★★★☆ | ≥0.70 组 future_mfe>5% 达 90.7%，有效 |
| 趋势分层 | ★★★★☆ | markup 阶段 future_mfe 11.53%，分层合理 |
| 时间衰减过滤 | ★★☆☆☆ | 52笔衰减交易选股失效，需额外过滤 |

### 5.2 价格机制评价

| 维度 | 评分 | 说明 |
|------|:---:|------|
| **入场定价** | **★☆☆☆☆** | **62.7% 信号未成交，损失 74.8% 潜在利润** |
| 止盈逻辑 | ★★★★☆ | MFE 捕获率 71%，止盈目标合理 |
| **止损/保本** | **★★☆☆☆** | **72.7% 止损交易后续涨 5%+，过早终止趋势** |
| 入场滑点 | ★★★☆☆ | 38% 有滑点，均值 -1.27%，可接受 |

### 5.3 三大核心问题排序

#### P0: 挂单定价过于保守 (损失最大)

**现状**: 挂单价 = V4.4 entry ≈ T0收盘 × 0.95  
**后果**: 91.6% 挂单价低于 7 天最低点，62.7% 信号无法成交  
**损失**: 5086% 潜在利润(占总 future_mfe 的 74.8%)

**建议**: 
- 方案A: 挂单价 = max(V4.4_entry, T0_收盘 × 0.98)
- 方案B: 挂单价 = T+1 竞价成交价 × 0.99
- 方案C: 分级定价 — 高确信信号(GBM≥0.70)用 0.98，低确信用 0.96

#### P1: 止损/保本机制过早终止趋势

**现状**: 83.2% 止损交易 MAE 未触及止损线，76.9% 是正收益出场  
**后果**: 72.7% 的止损交易后续涨 5%+，55.9% 被过早终止  
**损失**: 806% 潜在利润

**建议**:
- 保本线触发从 5% 下调到 3%（更早保护）
- 保本后的追踪止盈放宽: 允许回吐 MFE 的 40%→50%
- 增加"再入场"机制: 保本出场后若价格再破前高，自动回补

#### P2: 入场位置 > 50% 的信号应放弃

**现状**: 入场位置 > 50% 的 41 笔成交中，胜率仅 19.5%  
**建议**: 若 `(trigger_buy - 回测底) / (回测顶 - 回测底) > 0.5`，直接跳过
