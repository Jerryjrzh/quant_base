# Signal Generator 数据分析报告

## 一、数据概况

- 数据源: `data/result/SignalGenerator/master_signals.csv`
- 总记录数: **736,561** 条信号
- 日期范围: 2025-01-02 ~ 2026-04-29 (319个交易日)
- 股票数量: 5,454 只
- 策略: MORSE_FACTOR_SNIPER (apply_morse_sniper_strategy)

## 二、评分分布

| 评分 | 信号数 | 占比 |
|------|--------|------|
| 85 | 6,103 | 0.8% |
| 90 | 339 | 0.05% |
| **95** | **723,360** | **98.2%** |
| 100 | 123 | 0.02% |
| 110 | 5,664 | 0.8% |
| 115 | 972 | 0.1% |

**核心问题**: 98.2% 的信号都是 95 分（策略 base=95），评分系统几乎没有区分度。

## 三、入场门槛确认

所有信号必须通过 MA13 入场门槛才能拿到 base=95 分:

```
条件1: -4.8% ≤ MA13 乖离率 ≤ +8.0%
条件2: MA13 斜率 ≥ -3.0%
```

然后通过 T1/M15 因子加减分，最终 score ≥ 85 才输出。

## 六、核心矛盾

两个优化目标存在内在矛盾:
- **先跌后涨** → 低 B20 + 低 slope 更好 (回调到位的票)
- **振幅≥10%** → 高 B20 + 高 slope 更好 (波动大的票)

**唯一能同时提升两个指标的因子: MA20 slope ≤ 负值**

## 九、结论

1. **筛选条件方向正确** — MA13 入场门槛选出的股票，7天中位振幅 8.45%，波动充足
2. **评分系统失效** — 98.2% 信号 = 95 分，无区分度。V4.4 等级(A/B/C/D)对路径预测仅 1.6pp 差距
3. **MA20 slope 是金因子** — 唯一能同时提升"先跌后涨"和"振幅≥10%"的因子
4. **当前策略缺少 slope 上限** — 大量 slope 正值(已涨)的信号混入，拉低质量
5. **方案 C (slope≤-2% + 20CM) 最优** — 优质率 34.7%，是基准的 1.5 倍
