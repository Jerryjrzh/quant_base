## 一、ChatGPT思路的合理性确认

**核心诊断：**  
现有日线系统已将趋势、结构、量能、位置等信息充分编码，小时线再去检查MA、MACD、RSI等，只是同维度的重复，信息增量极低。这就是为什么Phase 1的小时线入场确认始终无法产生正向效果的原因。

**正确的小时线用途：**  
小时线不应是“信号确认器”，而应是“路径分类器”。它的独特价值在于：**在日线已经确定“有行情”的前提下，通过微观结构预测这波行情“会以怎样的路径展开”**——是顺滑上涨、震荡上涨，还是冲高回落。

这直接解决了当前系统的最大痛点：  
- MFE都是+20%，但路径不同导致实际盈亏差异巨大。  
- 路径差异在日线上难以区分，但在小时线上可以通过回调深度、频率、量能分布等特征捕捉。

**因此，小时线的正确使用方式是：**  
- 训练一个**小时线路径分类器**，预测未来22天的价格路径类型。  
- 将路径预测结果与日线Alpha得分结合，形成最终评分。  
- 执行层根据路径类型决定仓位和出场策略（顺滑满仓，震荡半仓，冲高回落的放弃或极轻仓）。

这个思路完全跳出了“加一层过滤器”的陷阱，转向了信息维度的真正升级。**完全合理，且符合当前系统的发展阶段。**

## 三、执行计划：小时线路径分类器（P0）

### 3.1 路径标签定义

针对每笔历史异动信号，利用其T0后22天的日线数据，计算两个关键指标：
- `max_drawdown`：未来22天内的最大回撤（从峰值到谷底）。
- `trend_smoothness`：日收盘价序列的线性拟合R²（衡量趋势的平滑程度）。

基于这两个指标，使用K-Means聚类（k=3）对历史信号进行分组，并人工验证其业务含义，最终映射为：
- **Class 0 - Smooth Trend（顺滑上涨）**：回撤小（<8%），趋势平滑（R²>0.6），适合满仓。
- **Class 1 - Pullback Trend（震荡上涨）**：回撤中等（8-15%），趋势有波折（R² 0.3-0.6），适合半仓或宽止损。
- **Class 2 - Failure（冲高回落）**：回撤大（>15%）或最终收益低，MFE虽高但路径恶劣，应放弃或极小仓位。

### 3.2 小时线特征提取

对于每个信号，获取其**T0日及之前20个交易日的60分钟K线数据**，提取以下维度的特征（仅依赖T0及之前数据，无未来信息）：

| 维度 | 特征举例 |
|------|---------|
| 趋势结构 | 60分钟MA20斜率，价格与MA60位置关系 |
| 波动特征 | 60分钟收益率标准差，日内振幅均值，跳空频率 |
| 量价关系 | 上涨小时量比均值，下跌小时量比均值，量价背离程度 |
| 回调形态 | 最近一次显著回调的深度、持续时间、回升速度 |
| 路径特征 | 近期创新高的频率，回踩均线的次数与成功率 |

目标是捕捉“这只股票最近在小时线级别上是怎么走的”，从而推断其后续路径特征。

### 3.3 分类器训练

- **输入**：上述小时线特征（~30-50维）。
- **输出**：三分类（Smooth/Pullback/Failure）。
- **模型**：LightGBM多分类，或简单的随机森林，重点是可解释性。
- **验证**：按时序划分训练/验证/测试集（2024年训练，2025年1-8月验证，2025年9月-2026年3月测试），确保无未来信息泄露。

### 3.4 与现有系统集成

- 训练好的路径分类器输出每个信号的`path_score_smooth`、`path_score_pullback`、`path_score_failure`三个概率。
- 最终执行决策：
  ```python
  final_score = operable_score * (1.0 * p_smooth + 0.5 * p_pullback + 0.0 * p_failure)
  ```
  其中权重可优化。
- 仓位：
  - 若预测为Smooth且日线强信号，满仓。
  - 若Pullback，半仓且放宽止损（用更宽的ATR倍数）。
  - 若Failure，直接过滤（或仅0.25倍极轻仓观察）。

### 3.5 回测验证

- 在测试集上，对比加入路径得分前后的整体表现（交易数、平均盈亏、胜率、PF）。
- 重点观察：冲高回落类信号是否被有效过滤或减仓，从而提升整体盈亏比。
