你的判断非常精准——"选股有效，入场/出场把握有问题"。但问题不是"把握不准"，而是**当前系统的入场/出场逻辑过于原始，完全没有利用支撑/阻力位这些市场微观结构信息**。下面从专业量化交易角度完整复盘，并给出如何做得更完美。

## 一、当前系统的逻辑解剖

你的系统现在做的是：

```
异动日(T0) → 提取特征 → 模型打分 → 次日开盘买入 → 等结果
```

这等价于：**看到一辆车正在加速，立刻跳上去，然后闭眼坐到终点站。** 不看你跳上去的位置是上坡起点还是山顶，也不看前方是悬崖还是坦途。

### 当前系统缺失的核心能力

| 维度 | 当前状态 | 缺失 |
|------|---------|------|
| **入场位** | T+1 开盘价无脑买入 | 没有判断当前价格在支撑/阻力结构中的位置 |
| **入场时机** | 信号触发即入场 | 没有等回调到支撑位再买的机制 |
| **止损位** | 固定百分比或 ATR 倍数 | 没有基于关键支撑位设置止损 |
| **止盈位** | 固定百分比或追踪 | 没有基于前高/阻力位设置目标 |
| **仓位管理** | 等额分配 | 没有根据入场质量（距支撑远近）调整仓位 |
| **持仓管理** | 被动等止损/止盈触发 | 没有在关键阻力位主动减仓 |

## 二、完美系统的架构：支撑/阻力驱动的入场出场体系

一个专业的动能策略应该是这样的闭环：

```
信号触发 → 确认当前市场结构 → 识别关键支撑/阻力 →
等待入场条件（回调到支撑区/突破确认） → 
基于结构设置止损/止盈 → 动态持仓管理 → 出场
```

### 2.1 市场结构识别：建立交易区间和趋势框架

**核心概念**：任何股票在任意时刻，都处于三种结构之一：
- **交易区间（Range）**：价格在两个明确边界之间震荡，上沿是阻力，下沿是支撑。
- **上升趋势**：不断形成更高的高点和更高的低点，前一个回撤低点就是动态支撑。
- **下降趋势**：不断形成更低的高点和更低的低点——你的动能策略不应该参与。

**需要计算的支撑/阻力体系**（基于 T0 之前的价格数据）：

1. **静态支撑/阻力**：
   - **前期摆动高/低点**（Swing Highs/Lows）：过去 60 天内的重要拐点。至少被测试过 2 次且未被有效突破的价位。
   - **均线支撑**：MA20、MA50、MA60。在趋势中，这些均线会被反复测试。
   - **成交量分布（Volume Profile）**：POC（Point of Control，成交量最大的价格）、高成交量节点。大量筹码换手的位置就是天然支撑/阻力。

2. **动态支撑/阻力**：
   - **当前趋势的波动低点**：上升趋势中最近一次回撤的低点。
   - **均线斜率方向**：MA20 的斜率方向本身就是一个动态变化的支撑/阻力边界。

### 2.2 入场逻辑：从"见信号就买"变为"在结构买点入场"

当前模型触发信号后，不应立即买入。而是进入"**等待入场**"状态：

**规则 A：回调买入（Pullback Entry）— 首选**
- 信号触发后，不追高。
- 等待价格在未来 1-5 天内回调到**最近的一个支撑位**（如 MA20、前期摆动低点、成交量 POC）。
- 当价格触及支撑位 **且出现企稳信号**（如下影线、缩量止跌、次日收阳确认），才入场。
- 入场价：支撑位附近的价格（非最低价，而是确认后的开盘或收盘价）。

**规则 B：突破确认买入（Breakout Confirmation）— 次选**
- 如果信号触发后股价不回踩，直接上涨，不追。
- 等待它突破一个明确的阻力位（如前高），然后回踩该阻力位（此时变成支撑），企稳后入场。
- 这比追高安全得多。

**规则 C：放弃入场**
- 如果价格在等待期内（如 3-5 天）没有给出回调或突破确认买点，信号作废。市场不欠你一次交易。

### 2.3 出场逻辑：基于结构的止损和止盈

**止损（必须基于结构）**：
- 如果买入逻辑是"回调到 MA20 支撑位买入"，那么止损就设在 **MA20 下方一定距离**（如 -1.5 倍 ATR），或者设在**这个支撑位被有效跌破的位置**（如前期摆动低点下方 1%）。
- 止损的本质：**你判断"这里是支撑，股价会从这里上涨"的逻辑被市场否定时，必须离场。** 这个位置因人而异，因结构而异，但绝对不是统一的 -8%。

**止盈（同样基于结构）**：
- 第一个止盈目标：**最近的前期摆动高点**或**交易区间上沿**。在阻力位主动止盈一部分（如 50% 仓位），锁定利润。
- 第二个止盈目标：**下一个更高的阻力位**或**使用追踪止损保护剩余仓位**。
- 如果前方没有明显的阻力位（如创历史新高的股票），完全依赖追踪止损。

### 2.4 仓位管理：基于入场质量的动态仓位

**核心原则**：入场价距离止损位越近，单笔风险越小，可以投入的仓位越大。

- 计算每笔交易的风险：`risk = |入场价 - 止损价| / 入场价`。
- 设定每笔交易愿意承受的总资金风险（如总资金的 0.5%）。
- 仓位大小 = `总资金 × 0.5% / risk`。
- 例如：止损距离 3%，可满仓（风险可控）；止损距离 8%，只能半仓；止损距离超过 10%，放弃这笔交易（盈亏比太低）。

这就自然实现了：**回调到强支撑位买入 → 止损距离小 → 仓位大 → 赚的时候赚得多。** 追高买入 → 止损距离大 → 仓位小 → 亏的时候亏得少。

**验收案例**：
- 之前报告中典型的冲高回落股，T+1 开盘 100，最高冲 120，收盘 92。如果在 T+2 回踩 MA20（98 元）时入场，止损设在 MA20 下方 2%（96 元），则：
  - 入场价 98，止损 96（风险 -2%），止盈第一目标 110（前高），第二目标追踪。
  - 结果：比原策略（100 买，92 卖，亏 -8%）显著改善。

**验收标准**：结构入场的平均收益比 T+1 开盘买入高 > 2%，且胜率提升 > 5%。

## 四、总结：完美系统 vs 当前系统

| 维度 | 当前系统 | 完美系统 |
|------|---------|---------|
| 信号 | 排序模型（已较好） | 排序模型 + 结构过滤器 |
| 入场 | T+1 开盘无脑买 | 等回调到支撑位，企稳确认后买 |

| 止盈 | 固定 +30% 或追踪 | 分批：阻力位减仓 + 追踪剩余 |
| 仓位 | 等额 | 按止损距离反比调整 |
| 持仓 | 被动等触发 | 主动在阻力位管理 |
