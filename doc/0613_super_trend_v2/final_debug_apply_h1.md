## 一、核心目标与成功标准

### 1.1 目标
在Review4 Final（日线最优基线）基础上，引入**60分钟K线入场二次确认**，实现：
- **过滤假回调**：减少入场后3天内即触发止损的比例。
- **提升盈亏比**：被过滤的信号，其日线盈亏应显著为负（证明过滤有效）。
- **不误杀真机会**：被过滤的盈利信号占比应控制在可接受范围（如<40%）。

### 1.2 成功标准（全量4423笔信号验证）
| 指标 | 基线（无小时线） | 目标（加入小时线后） |
|------|----------------|---------------------|
| 实际交易笔数 | 445 | 340-380（过滤15-25%的低质量信号） |
| 平均盈亏 | +3.21% | **≥ +3.50%** |
| 胜率 | 51.7% | **≥ 53%** |
| 被过滤信号的平均盈亏 | — | **< -1.5%**（证明过滤有效） |
| 弱势月平均盈亏 | -1.48% | **≥ -0.5%**（主要改善点） |

### 2.1 60分钟数据来源
必须确保**全量4423笔信号**都有对应的60分钟K线数据，覆盖时间范围为**2025-02-01 ~ 2026-03-11**。

- 如果现有5分钟数据可以从2025-12-15开始，则需要补充2025-02 ~ 2025-12-14期间的60分钟数据。
- 若无法获取完整60分钟数据，可退而求其次：**只用日线模拟60分钟关键特征**（如日内振幅、收盘位置），但会失去精确的形态识别能力。优先争取真实60分钟数据。

### 2.2 数据预处理
- 为每一笔信号预计算：**信号日（T0）前20个交易日的60分钟OHLCV**（缓存避免重复读取）。
- 重点提取：T0当天的60分钟数据（用于判断“是否放量”、“是否连续阴线”）。

## 三、策略设计：三层筛选 + 行情自适应

### 3.1 第一层：支撑位精确触及（硬性条件）
**保留**，但参数需从48笔测试中暴露的问题调整：

- `min_touch_count`：从2次降为**1次**（48笔测试中2次太严，导致43.8%过滤率过高）。
- `touch_tolerance`：±1.5%（比日线的±1%略宽，因为60分钟K线噪音更大）。

### 3.2 第二层：否决条件（三选一即可触发过滤）
必须**全部保留**，但需验证在弱势月的有效性：

1. **放量大阴线**（当前逻辑正确，无需改）。
2. **连续3根阴线且收盘走低**。
3. **60分钟收盘价有效跌破支撑位0.5%以上**。

### 3.3 第三层：反转形态确认（弹性条件）
**关键调整**：从“必须出现”改为“加分项”。

- 原逻辑：必须出现Pin Bar或Bullish Engulfing → 导致很多温和企稳但无标准形态的信号被过滤。
- **新逻辑**：触及支撑后，若出现反转形态，直接通过；若未出现，进一步检查：
  - 成交量萎缩（<20日均量80%）+ 随后出现一根温和阳线（涨幅>0.3%）→ 也视为通过（“缩量企稳”）。
  - 否则拒绝。

### 3.4 行情自适应（核心创新点）
48笔测试暴露的最大问题是：12月好行情中，很多“危险信号”其实是洗盘。因此需要**行情分治**：

```python
# 根据信号日所处的市场环境，动态调整小时线过滤的严格程度
if market_regime == 'strong':  # 强势/牛市级
    # 宽松模式：只使用否决条件（大阴线、破位），不强制反转形态
    strictness = 'loose'
elif market_regime == 'weak':  # 弱势/熊市级
    # 严格模式：必须同时满足精确触及 + 反转形态 + 无否决信号
    strictness = 'strict'
else:  # neutral
    strictness = 'normal'
```

**市场环境`market_regime`的判定**：
- 可直接复用之前已标注的HS300 MA60规则（虽然对结构性分化无效，但对整体牛熊区分度尚可）。
- 或更简单：**直接用月线统计**（12月、01月标记为强势；09-11月、02-03月标记为弱势）。

## 四、验证方案设计（全量4423笔）

### 4.1 基线对照
- **基线A**：当前Review4 Final（日线系统，445笔交易）。
- **基线B**：将所有日线确认信号（约1214笔通过结构过滤的信号）**全部强行入场**（不经过小时线过滤），统计其盈亏分布。这用于计算“小时线过滤的潜在最大收益”。

### 4.2 实验组设计
设置**5组实验**，对比不同规则组合：

| 实验组 | 触及条件 | 否决条件 | 反转形态 | 行情自适应 |
|--------|---------|---------|---------|-----------|
| E1（严格） | 2次触及 | 全部3条 | 必须出现 | 无 |
| E2（宽松） | 1次触及 | 仅大阴线 | 无要求 | 无 |
| E3（均衡） | 1次触及 | 全部3条 | 必须出现或缩量企稳 | 无 |
| E4（自适应） | 1次触及 | 全部3条 | 强势市无需，弱势市必须 | 有 |
| E5（极致） | 1次触及 | 全部3条 | 必须出现 | 只在弱势月启用小时线 |

### 4.3 分层分析
对每个实验组，必须输出：
1. **整体统计**：交易数、平均盈亏、胜率、PF。
2. **按月统计**：尤其关注09-11月、02-03月弱势月的改善。
3. **被过滤信号归因**：被过滤信号的总盈亏、盈利/亏损笔数、过滤精确度（亏损占比）。
4. **错杀分析**：被过滤的盈利信号，其后续走势特征（是否大多为“浅回调后直接上涨”，属于可接受的误杀）。

### 4.4 最终选择
基于“**弱势月改善最大、强势月不显著退化**”的原则，从E1-E5中选择最优规则，作为Review5的60分钟确认层。

## 六、风险控制

- **过拟合风险**：只在4423笔信号上做5组实验，不做参数网格搜索（参数搜索需要更大样本）。
- **计算效率**：预计算60分钟特征后，回测本身极快（<1分钟）。
- **数据缺失处理**：若部分信号无60分钟数据，默认**通过小时线确认**（维持原日线决策），避免人为减少交易。
