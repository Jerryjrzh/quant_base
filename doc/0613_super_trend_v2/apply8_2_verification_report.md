## 一、内生特征定义

| 特征 | 计算方式 | 含义 |
|------|---------|------|
| `consecutive_loss_streak` | 最近已成交信号的连续亏损笔数 | 策略当前处于亏损周期 |
| `stock_recent_loss_count` | 同股前5个信号中 stock_return_20d<0 的个数 | 个股动量衰退 |
| `signal_surge` | 当日信号数 / 20日均值 | 信号突然暴增(过热) |
| `daily_signal_count` | 当日信号总数 | 信号拥挤度 |
| `date_high_rsi_ratio` | 同日期信号中 RSI>70 的占比 | 市场超买信号占比 |
| `date_avg_bias_ma20` | 同日期信号的 bias_ma20 均值 | 整体偏离度 |
| `date_avg_rsi` | 同日期信号的平均 RSI | 市场热度 |
