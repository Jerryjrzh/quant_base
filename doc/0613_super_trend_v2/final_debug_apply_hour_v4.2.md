```python
# 回调深度：从入场价开始的最大跌幅
cumulative_min = path['low'].cummin()

min_idx = drawdown.idxmin()
if min_idx < len(path) - 1:

    rebound_pct = subsequent_high / path['low'].iloc[min_idx] - 1
else:
    rebound_pct = 0.0
```

## 三、从波动区间反推入场参数的逻辑

### 3.1 入场点设置原则

**不是固定值，而是与回调深度挂钩。** 对每一类回调深度的信号，我们设置不同的入场触发价：

```python
# 基于数据统计（假设统计结果）
entry_triggers = {
    'shallow': -0.03,   # 回调3%时入场
    'moderate': -0.08,  # 回调8%时入场
    'deep': -0.12,      # 回调12%时入场
    'very_deep': -0.18  # 回调18%时入场（需有强反弹数据支持才启用）
}
```

入场确认：在价格触及触发价后，出现缩量阳线或下影线确认（沿用已有的K线形态逻辑）。

### 3.2 止盈设置原则

止盈目标不是固定的百分比，而是**基于回调后的平均反弹高度**，并打一个折扣（比如80%分位数），确保高概率触达。

```python
# 统计每组回调后的反弹高度分布
rebound_dist = signals[signals['max_dd'] in range].groupby('max_dd_range')['rebound_pct']

# 取每组反弹高度的80%分位数作为止盈目标
take_profit_levels = rebound_dist.quantile(0.8)
```

### 3.3 止损设置原则

止损应设在**入场触发价下方一定缓冲**，确保不被正常波动洗出。缓冲大小同样根据该组回调深度的波动率（ATR）来定。

```python
# 止损 = 入场触发价 - N倍的该组平均ATR
stop_loss = trigger_price - atr_multiplier * avg_atr_in_group
```
