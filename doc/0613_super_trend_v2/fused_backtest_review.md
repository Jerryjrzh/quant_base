## 全局诊断：融合方向正确，但“形态→入场”的映射逻辑需要根本性重构

当前的融合结果（胜率下降 9.3%，止损率上升 10.6%）不是方向错了，而是**形态特征与入场条件的匹配方式出了问题**。让我从全局视角拆解清楚。

---

## 一、当前融合方案的本质错误

当前的融合逻辑简化后是这样的：

```
V2形态特征 → 融合支撑位（调整置信度）
             → 放宽入场条件（高置信度时少要求K线确认）
             → 调整止损缓冲（高置信度用更紧止损）
```

这个逻辑链条有一个致命假设：**“形态越好，支撑越可靠，就可以用更宽松的入场条件”。**

但回测数据证明了这个假设是错的：

| 逻辑环节 | 假设 | 实际结果 | 结论 |
|---------|------|---------|------|
| 放宽入场（relaxed_confident） | 高置信度支撑不需要严格的K线确认 | 多出的120笔交易拉低整体胜率9.3% | **错误** |
| 提高置信度 | ma_glue形态的支撑更可靠 | ma_glue组合形态胜率仅27.7%，止损率72.3% | **错误** |
| pit_bottom支撑 | 坑底是强支撑 | 367笔交易胜率31.3%，平均亏损-0.27% | **定位不准** |

**核心问题：形态特征是为“选股”设计的（预测22天内能否大涨），不是为“入场时机”设计的（判断今天是不是好的买点）。这两个目标的特征不能直接混用。**

## 二、从全局角度重新理解三类形态与市场结构的关系

### 2.1 形态特征的本质含义（从入场角度重新解读）

| V2形态 | 在选股端的含义 | 在入场端的真实含义 | 对入场的实际影响 |
|--------|-------------|-----------------|----------------|
| **ma_glue（均线束粘合）** | 即将变盘 | **方向不确定**。粘合后可以向上突破，也可以向下破位。 | 粘合本身不提供支撑可靠性信息。**不应提高置信度。** |
| **washout（MA60洗盘）** | 假破位洗盘，主力收集筹码 | MA60被砸穿后收回，**确认MA60是有效支撑**。 | 这是最强的入场信号。MA60支撑被实战验证。 |
| **pit_rebound（坑底反弹）** | 从近期低点反弹 | **反弹可能只是死猫跳**。坑底是否真正企稳，需要额外确认。 | 单独使用效果好（+1.08%），但需要严格K线确认。 |

### 2.2 从入场角度，形态分三类

| 入场质量 | 形态 | 特征 | 入场策略 |
|---------|------|------|---------|
| **高质量** | washout（MA60洗盘） | 支撑位被实战验证过 | 标准K线确认即可，止损可稍紧 |
| **中等质量** | pit_rebound（坑底反弹） | 有反弹动能，但底部未确认 | 必须严格K线确认，止损应稍宽（给假反弹留空间） |
| **不确定** | ma_glue（均线束粘合） | 方向不明 | **不作为入场加分项**，退化为普通支撑位 |

### 3.3 按形态差异化止损（核心改变）

形态不是用来放宽入场的，而是用来**调整止损策略**的：

```python
def set_initial_stop_by_pattern(entry_price, support_used, atr, v2_features, max_stop_loss_pct=0.05):
    """根据入场形态类型差异化止损"""
    hard_stop = entry_price * (1 - max_stop_loss_pct)
    
    if support_used is None:
        return hard_stop
    
    # 判断形态类型
    is_washout = v2_features.get('washout_ma60_flag', 0) == 1
    is_pit_rebound = v2_features.get('price_rebound_from_pit', 0) > 0.03
    
    if is_washout:
        # 洗盘形态：支撑被验证过，止损可以紧一些
        atr_mult = 0.75
    elif is_pit_rebound:
        # 坑底反弹：需要给假反弹留空间，止损应稍宽
        atr_mult = 1.25
    else:
        # 标准
        atr_mult = 1.0
    
    structural_stop = support_used.price - atr_mult * atr
    return max(structural_stop, hard_stop)
```

**逻辑**：
- 洗盘形态：支撑已通过“破位收回”的压力测试，可靠性高，止损可以紧，提高盈亏比。
- 坑底反弹：反弹性质未确认，需要更宽的止损容忍度，避免被假反弹的噪声震出。
- 其他：标准处理。

## 六、全局视角总结

**融合不是把两个系统的参数拼在一起调权重，而是理解每个形态信号在市场结构中的真实含义。**

- **ma_glue（均线束粘合）** → 选股端有效（预示变盘），但入场端无效（方向不确定）→ 选股时使用，入场时不加分。
- **washout（MA60洗盘）** → 选股端有效（主力行为），入场端也有效（支撑被验证）→ 两端都加分，止损可更紧。
- **pit_rebound（坑底反弹）** → 选股端有效（从低点反弹），入场端需谨慎（可能是假反弹）→ 选股时使用，入场时严格确认且放宽止损。

**闭环应该是：选股端告诉执行端“这只股票有哪种形态”，执行端根据形态类型选择对应的入场标准和止损策略。不是统一调参数，而是分形施策。**
