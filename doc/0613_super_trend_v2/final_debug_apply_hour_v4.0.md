## 一、原因1的路径分析：按T0后跌幅分层

### 1.1 分析方法

对4423笔信号，计算每笔信号T0后22天内的价格路径，提取两个关键指标：
- **最大跌幅（max_drawdown）**：从T+1开盘价开始，价格最大下跌幅度。
- **最终收益（final_return）**：T+22收盘价相对T+1开盘价的涨跌幅。

按最大跌幅分层，统计每层的：
- 信号数量、占比
- 最终收益均值和中位数
- MFE（期间最高涨幅）均值
- 盈利交易占比
- 被当前系统实际交易的信号在这一层的分布

### 1.2 分层定义

```python
drawdown_bins = [0, 0.015, 0.03, 0.06, 0.10, 0.15, float('inf')]
bin_labels = ['<1.5%', '1.5-3%', '3-6%', '6-10%', '10-15%', '>15%']
```

### 1.3 预期产出

一张表格，清晰展示：
- 跌幅<3%的信号：占比多少，最终收益如何，当前系统是否抓住了。
- 跌幅3-10%的信号：占比最大，最终收益可能为负（冲高回落主力），当前系统的出场是否合理。
- 跌幅>15%的信号：占比多少，是否应该直接放弃（即使MFE高，路径太差）。

**这个分析不需要任何新数据，完全基于现有`pure_mfe_analysis.csv`的22天路径。**

### 1.4 出场与高点差异分析

对每个跌幅层，进一步分析：
- 如果在这层的**最低点**入场（最优入场），最终收益会是多少？（计算MFE的捕获潜力）
- 当前系统的实际入场价（T+1开盘）与最低点的差距是多少？（入场成本差异）
- 当前系统的出场触发原因分布（止损/止盈/动态出场）在这层的差异。

**产出**：一个矩阵表，横轴是跌幅分层，纵轴是出场方式，中间是平均盈亏。

## 二、原因2的差异化出场验证

| 跌幅层 | 测试参数 |
|--------|---------|
| <3% | 止盈放宽（30%→40%），止损收紧（8%→5%），因为回撤小的股票趋势强 |
| 3-6% | 止盈标准（20%），止损标准（8%），当前配置 |

## 三、选股公式验证

您提供的通达信公式，核心是两组指标：

1. **金钻趋势**：XMA双重平滑后的价格通道下轨（均线偏移线）。
2. **BBI**：5/10/20/30日均线的等权均值。

### 3.1 公式转译与特征提取

```python

# 等价于: 2 * XMA(XMA(L,25),25) - XMA(XMA(H,25),25)
# 简化为: 双重平滑低点的两倍 减去 双重平滑高点

# 对每笔信号，计算T0当天的以下特征：
features = {
    'golden_trend': 2 * xma(xma(low,25),25) - xma(xma(high,25),25),  # 金钻趋势值
    'golden_trend_slope': 金钻趋势的5日斜率,
    'price_vs_golden': close / golden_trend - 1,  # 价格相对金钻趋势的位置
    'bbi': (ma5+ma10+ma20+ma30)/4,
    'price_vs_bbi': close / bbi - 1,
    'bbi_slope': BBI的5日斜率,
    'golden_cross': 金钻趋势是否上穿金牛2（EMA(金钻,25)）
```
