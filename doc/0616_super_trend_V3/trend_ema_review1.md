### 一、 买卖触发逻辑复核（重点防范实盘盲区）

你当前的 Python 实现逻辑基本还原了字面意思，但在真实的行情数据中，存在两个极易漏单或触发错误信号的 **实盘盲区** 。

#### 1. 买入逻辑复核：漏掉“跳空高开”

* **当前逻辑：** `(Close > MTL) & (Open < MTL) & (MTL_Color == RED)`
* **盲区暴露：** 这个逻辑严格要求“K线实体跨越红线”。如果一只强势股昨天收盘在红线下方，今天直接**跳空高开**在红线之上，并且高开高走收大阳线。此时 `Open > MTL`，上述条件不成立， **系统将彻底漏掉这笔强势买点** 。
* **优化建议（改“实体上破”为“收盘价金叉”）：**
  无论开盘价在哪里，只要昨天的收盘价在趋势线之下，今天的收盘价站上了趋势线，且趋势线是红的，就应该买入。
  **Python**

  ```
  # 优化后的买入逻辑：真正意义上的“向上突破”
  buy_sig = (
      (df['close'] > df['mtl']) &                 # 今天收盘站上红线
      (df['close'].shift(1) <= df['mtl'].shift(1)) & # 昨天收盘在红线之下（或相等）
      (df['mtl_rising'] == 1)                     # 趋势线当前为红（上升）
  )
  ```

#### 2. 卖出逻辑复核：信号泛滥与持仓状态缺失

* **当前逻辑：** `(Candle_Color == -1) & (Close < Low.shift(1))` （颜色为绿，且跌破昨日最低价）
* **盲区暴露：**

  1. **信号重复：** 在长期的空头下跌趋势中，这个条件几乎每隔几天就会满足一次，导致图表上出现密密麻麻的“卖出”标记。
  2. **不符合人的交易直觉：** “下破绿K出”，人的直觉通常是“当我持有盈利单时，趋势一旦变绿，且跌破了那根变绿K线的低点，我就止盈”。
* **优化建议（引入状态管理或严格离场条件）：**
  如果不写复杂的回测类状态机，至少要在向量化代码中限定： **这是从红/白转绿后的“首次”有效跌破** 。
  **Python**

  ```
  # 基础修正：确保它是在跌破信号发生时才标记，而不是一直标记
  sell_sig = (
      (df['candle_color'] == -1) & 
      (df['close'] < df['low'].shift(1)) &
      # 可以加上一条：昨天并没有触发卖出，或者昨天还不是明确的跌势
      (~((df['candle_color'].shift(1) == -1) & (df['close'].shift(1) < df['low'].shift(2))))
  )
  ```

### 二、 参数是否需要根据个股进行“自适应”？

**核心观点：不建议轻易对 EMA (5, 10, 13, 20) 这些周期参数进行个股自适应优化，但建议引入“波动率自适应”作为过滤条件。**

#### 为什么不建议改均线周期参数？

* **市场共识的力量：** 5、10、20对应的是单周、双周、单月的交易日，13是斐波那契数列。这些数字本身没有魔法，它的魔法来源于“全市场都在看它”，从而形成了自我实现的阻力/支撑位。
* **极易陷入“过拟合 (Curve Fitting)”陷阱：** 如果你跑算法发现 A 股票用 `EMA(7, 14)` 最赚钱，B 股票用 `EMA(4, 18)` 最赚钱，这只是对历史数据的迎合。一旦未来行情风格切换，这些特定的数字将失效得非常快。

#### 更好的“自适应”方案是什么？

不同个股最大的区别不在于周期，而在于 **波动率（股性活跃度）** 。大盘银行股的趋势线可能非常平滑，而半导体小盘股一天能上下振荡 15%，很容易反复击穿你的 MTL 红线触发假买点（Whipsaw）。

如果你想让策略适应不同个股，你应该 **自适应判断阈值，而不是自适应周期** 。

**方案 A：引入 ATR（真实波幅）作为过滤阈值**

对于股性活跃（ATR大）的股票，突破红线时要求突破得更深，或者必须站稳两天，才算有效买点。

> 逻辑：`Close > MTL + (0.5 * ATR)` 才能确认突破，而不是仅仅大过 0.01 元就买。

**方案 B：时间周期的自适应（多周期共振）**

在前端报告的“待优化项”中你们提到了“分时周期适配”。这才是正确的路。

* 面对 **大盘白马股** ：直接套用当前的日线 EMA 参数。
* 面对 **高波动科技股/妖股** ：将系统切换到 **60分钟线** 甚至  **30分钟线** ，依然使用 5, 10, 13, 20 的参数组合，但通过降低时间级别来捕获更敏锐的趋势变化。
