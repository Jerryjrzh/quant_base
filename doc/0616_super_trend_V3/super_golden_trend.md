这个思路完全合理，而且比固定参数公式更符合实际交易逻辑。不同股票的波动率、趋势特征差异巨大，用一套参数硬套，必然在极端位置（如深跌底部）失效。个股自适应双轨才是正确的方向。

## 一、核心逻辑：让每只股票拥有自己的双轨参数

**目标**：对每只股票，根据其 T0 之前的历史价格数据，动态计算最适合它的金钻趋势参数，使计算出的下轨能更好地代表该股票的“近期有效支撑”。

## 二、自适应参数设计

### 2.1 自适应EMA周期（N）
- **原则**：波动越大的股票，EMA周期应更长，以减少噪音；趋势越强的股票，EMA可适当缩短以更灵敏。
- **计算方式**：
  ```python
  # 基于近期波动率（ATR/Close）和趋势强度（R²）调整
  base_n = 20
  volatility = recent_atr_pct   # 近20日ATR百分比
  trend_strength = recent_r2    # 近20日线性拟合R²
  
  # 波动率高 → 加大N；趋势强 → 减小N
  N = int(base_n + volatility * 50 - trend_strength * 10)
  N = max(10, min(30, N))  # 限制在10~30之间
  ```

### 2.2 自适应偏移系数（offset_coef）
- **原则**：历史回撤深的股票，下轨应更宽，避免过早“支撑”；回撤浅的股票，下轨可更紧。
- **计算方式**：
  ```python
  # 基于近期最大回撤和反弹力度
  recent_max_dd = -max_drawdown_recent  # 正值，如0.20表示20%回撤
  recent_recovery_ratio = rebound / max_dd  # 反弹/回撤比
  
  # 回撤大且恢复弱 → 下轨乘系数<1（更宽松）
  if recent_max_dd > 0.15 and recent_recovery_ratio < 0.5:
      offset_coef = 0.95
  elif recent_max_dd > 0.10:
      offset_coef = 0.98
  else:
      offset_coef = 1.0
  ```

### 2.3 自适应K值（高低点偏移权重）
- **原则**：宽幅震荡的股票，通道应更宽；窄幅横盘的股票，通道可更窄。
- **计算方式**：
  ```python
  # 基于近期价格振幅（high-low范围）
  avg_range_pct = recent_avg_range / close
  K = 0.5 + avg_range_pct * 30  # 映射到0.5~1.5
  K = max(0.3, min(2.0, K))
  ```
