   ---

   一、需求分析

   1.1 现状

   path_analysis_v42.py 已实现：
   - Step 1: 对 4423 个 T0 信号，计算 T+1~T+22 的路径指标（最大回调、反弹、MFE）
   - Step 2: 按回调深度分层（03%, 35%, ..., >20%），统计每层反弹潜力，反推入场参数
   - Step 3: 分层策略回测（触发价入场 + 固定止盈止损）
   - Step 4: 与原系统对比报告

   1.2 核心差距（现有脚本 vs 文档描述的理想系统）
   ┌──────────┬───────────────────────────────┬──────────────────────────────────────────────┐
   │ 维度     │ 现有 v4.2                     │ 文档要求                                     │
   ├──────────┼───────────────────────────────┼──────────────────────────────────────────────┤
   │ 位置标记 │ 无。仅按回调深度分层          │ 需在 T-120~T-1 评估周期计算                  │
   │          │                               │ Position_Ratio，标记为深渊底部/主升浪/高位区 │
   │ 趋势状态 │ 无                            │ 需标记 BBI 方向、MA13 多头排列、均线发散状态 │
   │ 波动率   │ 无                            │ 需标记 ATR(20) 作为动态网格依据              │
   │ 状态机   │ 无。简单的逐日触发判断        │ 需 WAITING→OBSERVING→HOLDING                 │
   │          │                               │ 三态机，支持"触发后挂单等待深调"             │
   │ 入场确认 │ 仅价格触达触发价              │ 需量价确认（缩量、长下影线、MACD金叉等）     │
   │ 动态止盈 │ 固定比例（止盈=反弹中位*0.8， │ 需根据位置+波动特征动态调整，底部用60%分位， │
   │ 止损     │ 止损=5%）                     │ 主升浪用80%分位                              │
   │ 交叉验证 │ 仅回调深度单维度              │ 需 Position_Zone × 回调深度 双维度交叉       │
   └──────────┴───────────────────────────────┴──────────────────────────────────────────────┘
   1.3 功能需求                                                 
                                                                                                   
   FR-1: 多周期特征标记模块                                                                        
   - FR-1.1: 计算 T-120~T-1 的 Position_Ratio（120日高低点分位）                                   
   - FR-1.2: 计算 BBI 多空方向（BBI 斜率 / close vs BBI）                                          
   - FR-1.3: 计算 MA13 趋势状态（多头排列判定：MA13 > MA55 且 MA13 向上）                          
   - FR-1.4: 计算 ATR(20) 波动率标记                                                               
   - FR-1.5: 综合标记为三类位置区域：深渊底部（Pos<0.2）、主升浪中继（0.3~0.7）、高位风险区（>0.8）
                                                                                                   
   FR-2: 状态机回测引擎                                                                            
   - FR-2.1: 三态机（WAITING / OBSERVING / HOLDING）                                               
   - FR-2.2: T0 触发后进入 OBSERVING，根据位置区域计算目标入场价                                   
     - 深渊底部：触发价附近 0~-3%（左侧吸筹）                                                      
     - 主升浪：触发价 -8%~-12%（等深调后右侧狙击）                                                 
   - FR-2.3: OBSERVING 期间（T+1~T+10）逐日检查是否跌入目标区间 + 确认条件                         
   - FR-2.4: HOLDING 期间动态止盈止损（基于位置分层的分位数）                                      
   - FR-2.5: 观察期超时未入场则放弃，重置为 WAITING                                                
                                                                                                   
   FR-3: 位置×回调交叉验证                                                                         
   - FR-3.1: 按 Position_Zone × DD_Tier 双维度统计反弹特征                                         
   - FR-3.2: 为每个交叉单元格生成独立的入场/出场参数                                               
   - FR-3.3: 输出交叉热力表                                                                        
                                                                                                   
   FR-4: 对比报告                                                                                  
   - FR-4.1: 状态机策略 vs 原 v4.2 分层策略 vs 原系统 Review4 三方对比                             
   - FR-4.2: 按 Position_Zone 分组的胜率/PF/平均盈亏                                               
   - FR-4.3: 验证"位置决定定性"假设是否成立                                                        
                                                                                                   
   1.4 非功能需求                                                                                  
                                                                                                   
   - 复用 data_loader 和 _load_daily_via_60m 数据加载管道                                          
   - 信号源复用 review4_final_backtest.csv                                                         
   - 输出到 doc/0616_super_trend_V3/ 目录                                                          
   - T-120 评估周期需要额外加载信号前的历史数据（约 200 个交易日的 60m 数据）

   2.2 核心数据结构                                                                                
    # 信号标记                                                                                     
    @dataclass                                                                                     
    class SignalTag:                                                                               
        signal_idx: int                                                                            
        position_ratio: float      # 0~1, 120日分位                                                
        zone_tag: str              # 'abyss_bottom' | 'main_wave' | 'high_trap'                    
        trend_tag: str             # 'bull_aligned' | 'neutral' | 'bear_aligned'                   
        bbi_direction: str         # 'up' | 'down'                                                 
        ma13_slope: float          # MA13斜率                                                      
        atr20: float               # 20日ATR                                                       
        atr20_pct: float           # ATR/Close 百分比                                              
                                                                                                   
    # 状态机交易记录                                                                               
    @dataclass                                                                                     
    class Trade:                                                                                   
        signal_idx: int                                                                            
        zone_tag: str                                                                              
        dd_tier: str                                                                               
        t0_date: datetime                                                                          
        t0_close: float                                                                            
        golden_trend_t0: float                                                                     
        state_entry_date: datetime  # 进入OBSERVING的日期                                          
        target_entry_price: float                                                                  
        actual_entry_price: float                                                                  
        entry_confirm_tags: list   # ['volume_shrink', 'long_lower_shadow', ...]                   
        tp_price: float                                                                            
        sl_price: float                                                                            
        exit_date: datetime                                                                        
        exit_price: float                                                                          
        exit_reason: str           # 'tp' | 'sl' | 'expire' | 'abandoned'                          
        pnl: float

   1. 数据量: 4423 信号 × 每笔需加载 ~250 天 60m 数据用于 T-N                                      
   标记，数据加载是瓶颈。建议对历史数据做本地缓存                                                  
   2. Golden_Trend 价格: 需要额外计算双重 EMA 指标（替代 XMA），需确认 T-120 之前的数据量足够预热  
   3. 入场确认条件: 文档提到的缩量、长下影、MACD                                                   
   金叉等条件需定义量化阈值，建议先做宽松版本，后续迭代收紧
