## 二、自适应参数计算逻辑（基于一年数据）

我们不只是简单取平均值，而是提取能够反映股票“极端情况”和“常态”的特征，确保下轨在深跌时能兜住底，在震荡时不会太宽。

### 2.1 自适应 EMA 周期 N
通过计算过去250日的 **ATR/收盘价比值** 的均值，以及 **趋势持续性**，动态调整 N。

```python
def calc_adaptive_n(df_250):
    """
    波动越大 → N 越大 (平滑，减少噪音)
    趋势越强 → N 越小 (灵敏，紧跟趋势)
    """
    atr_pct = calculate_atr_pct(df_250, period=20).mean()  # 平均真实波幅百分比
    # 趋势强度用 50日线性回归的 R²
    close = df_250['close']
    x = np.arange(len(close))
    slope, intercept, r_value, p_value, std_err = linregress(x, close)
    trend_r2 = r_value ** 2
    
    base_n = 20
    n = int(base_n + atr_pct * 40 - trend_r2 * 10)
    return max(10, min(30, n))
```

### 2.2 自适应偏移系数 (offset_coef)
通过计算过去250日中的 **最大回撤深度** 和 **反弹恢复程度** 来设定。

```python
def calc_adaptive_offset(df_250):
    """
    历史回撤深且恢复弱 → 系数 < 1 (下轨更低，更宽松)
    历史回撤浅且恢复强 → 系数 = 1 (保持)
    """
    # 计算滚动最大回撤
    roll_high = df_250['high'].rolling(60, min_periods=1).max()
    roll_dd = (df_250['low'] / roll_high - 1).min()  # 最大回撤 (负值)
    max_dd = -roll_dd  # 转为正值
    
    if max_dd > 0.25:    # 历史有超过25%的回撤
        return 0.95
    elif max_dd > 0.15:
        return 0.98
    else:
        return 1.0
```

### 2.3 自适应 K 值 (高低点偏移权重)
根据过去250日的 **价格振幅 (high-low)/close** 均值设定。

```python
def calc_adaptive_k(df_250):
    """
    振幅大 → K 大 (通道更宽)
    振幅小 → K 小 (通道更窄)
    """
    avg_range_pct = ((df_250['high'] - df_250['low']) / df_250['close']).mean()
    k = 0.5 + avg_range_pct * 30
    return max(0.3, min(2.0, k))
```
