# 更合理的方法

不是调参数对齐单个股票。

而是研究：

```python

MACD参数

哪个组合

最稳定
```

---

例如：

```python
MACD

(5,13,4)

(8,21,6)

(12,26,9)

(18,36,9)
```

---

统计：

```python

```

的样本。

---

看看：

```text
哪组参数

最早发出信号

同时误报最低
```

---

这样得到：

```text
全市场最优参数
```

而不是：

```text
某个股票最优参数
```
