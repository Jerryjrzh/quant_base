# 为什么很多人觉得KDJ、RSI很好用

因为人的大脑天然会做模式识别。

例如回头看历史：

```text
底部

↓

KDJ金叉

↓

上涨50%
```

或者：

```text
MACD金叉

↓

主升浪启动
```

看起来规律非常明显。

但如果你统计全市场：

```text
KDJ金叉
```

可能出现：

```text
10000次

上涨 5100次
下跌 4900次
```

优势极小。

---

# 真正有价值的是

不是：

```text
MACD金叉
```

而是：

```text
在什么位置出现MACD金叉
```

例如：

### 场景A

```text
价格

距离MA240

+80%
```

此时：

```text
MACD金叉
```

大概率只是加速末端。

---

### 场景B

```text
价格

回踩MA150

距离MA240

+5%
```

同时：

```text
MACD金叉
```

价值就高很多。

---

所以实际上：

```text
位置
决定胜率

指标
决定时机
```
